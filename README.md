## التشغيل على هذا الجهاز

1. شغّل `scripts/start.ps1` من PowerShell. يستخدم البيئة الحالية ويشغّل Ollama الموجود في `D:/RiwaqRuntime` عند الحاجة، دون تمكين السحابة.
2. افتح `http://127.0.0.1:8765`، ثم شغّل `.\scripts\pair-browser.ps1 -Copy` بنفس هوية Windows ومجلد البيانات. الصق الرمز في بوابة الاقتران؛ لا ترسله في المحادثات. يتحقق الأمر من هوية الخدمة قبل إصدار رمز صالح لخمس دقائق ولمرة واحدة.
3. اكتب رسالة. اختر «استند إلى المصادر» فقط عند الرغبة في إجابة مقيدة بملفات المشروع. من الإعدادات، تعرض «درع رواق · حماية التنفيذ» تلخيص ملف صغير محليًا ودليل منع إرساله إلى الخارج.
4. اختر مشروعًا أو أنشئ آخر. المحادثات والتعليمات والمصادر مستقلة. زر تعديل الرسالة ينشئ فرعًا ويحفظ الأصل. إنهاء جلسة المتصفح يسحب وصولها؛ لا تعيد الواجهة العمليات المعدلة تلقائيًا بعد الاقتران.

تحديث الأمن 15 نوفمبر: [درع رواق](docs/RIWAQ_GUARD.md) يعمل في نطاق موثق، و[قبول المرحلة الثامنة محجوب](docs/RIWAQ_SECURITY_ACCEPTANCE.md). كتابة التفضيلات الشخصية الجديدة وحقنها والتوليد السحابي محجوبة. عزل Docker الفعلي يغطي المسارات المحددة فقط؛ لا شهادة ASVS أو مراجعة أمنية بشرية مستقلة مكتملة أو اعتماد للحزمة الأصلية. [الاعتماديات المحدثة واختبارها](reports/security-update-validation.json) لا تعني خلو كل المكونات من الثغرات. بيانات المشروع وأعماله السابقة محفوظة.

## إعداد نسخة جديدة

المتطلبات: Python 3.12، Node 22.12 أو أحدث متوافق، Ollama محلي. بعد نسخ المشروع:

```powershell
uv venv --python 3.12 .venv
uv pip install --python .venv/Scripts/python.exe -r requirements.lock.txt
npm --prefix frontend ci
npm --prefix frontend run build
$env:OLLAMA_NO_CLOUD='1'
ollama serve
```

على جهاز جديد فقط، يمكن تنزيل النموذج مرة واحدة بأمر `ollama pull qwen3:4b-instruct` بعد مراجعة الميزانية والمساحة. **لا تعِد تنزيله على هذا الجهاز؛ أوزانه موجودة.** بعد الإعداد يمكن الاستدلال دون اتصال خارجي. شغّل `.venv/Scripts/python.exe -m backend.launcher`. صور Docker وموديلات الصور والصوت اختيارية ولها إعدادات محلية مثبتة؛ التطبيق لا يجلبها تلقائيًا.

لا تثبّت خدمة الجهاز على عنوان عام. الحسابات في خدمة منفصلة موثقة في [دليل المزامنة](docs/SYNC.md). النسخ اختياري ويدوي ومشفّر في المتصفح، والاستعادة تنشئ مشروعًا جديدًا. قاعدة البيانات في `data/riwaq.sqlite3` للمصدر، وفي مجلد بيانات المستخدم للحزمة.

## الاستخدام

- `Enter` يرسل؛ `Shift+Enter` لسطر جديد؛ `Esc` يوقف التوليد؛ `Ctrl+K` يركز حقل الكتابة.
- زر المصادر القديم يرفع PDF نصيًا أو DOCX أو TXT/Markdown/CSV/code؛ PDF/DOCX يحتاجان صورة المحلل المحلية المهيأة. الاستشهاد يعرض المقطع وصفحة PDF أو الأسطر. الصور والصفحات الممسوحة تستخدم مساحة المستندات وOCR المهيأ فيها؛ ذلك مسار منفصل بحدود جودة وعزل معلنة.
- «مكتبة المعرفة» تدير المصادر العامة والحقوق والحزم والاستيراد والتحديث والإلغاء والاستئناف. فعّل «المعرفة العامة» بجانب محرر الرسالة لاستخدامها؛ ملفات المشروع الخاصة خيار منفصل. الاستيراد من الإنترنت يتطلب الوضع الهجين وإذن المهمة، والبحث في المكتبة المحفوظة يعمل محليًا.
- المستندات تحفظ نسخًا ومقارنة واستعادة. معلومات المشاريع والحقائق منفصلة عن التفضيلات الشخصية؛ لا حفظ شخصي تلقائي. قراءة السابق وحذفه متاحان، بينما كتابة التفضيلات الشخصية الجديدة وحقنها محجوبان حتى قبول المرحلة8.
- حالة المشروع تحفظ الهدف والقرارات والمنجزات والعوائق والخطوة التالية من أحداثك المسجلة. سجل النشاط يصف العمليات الفعلية، ولا يستنتج أن المشروع اكتمل من مجرد إجابة.
- مساحة البرمجة تتطلب اختيار مجلد. قراءة وبحث ثم اقتراح نص وdiff. التطبيق والتراجع يتطلبان أمرًا صريحًا ويُرفضان إن تغيّر الملف بعد المعاينة. فحص نسخة محدودة يتطلب Docker المحلي والصورة والإعداد الموثق؛ يرفض العمل عند غيابها ولا يستخدم المضيف بديلًا. [حدود العزل الفعلية](reports/completion-isolation-live/report.json).
- فهم الصور يستخدم Qwen3-VL المحلي، وتفريغ Whisper من المصدر يحتاج `RIWAQ_WHISPER_MODEL`؛ راجع العربية الناتجة لأن أخطاءها مقاسة. لا نطق عربي معتمد. مساحة الصور والتصميم الجديدة تربط الطبقات والنسخ والمهام الفعلية؛ توليد الخلفية منفصل عن كتابة النص الحرفي. اختُبر PNG في المتصفح، وJPEG/WebP عبر العامل والتخزين بعد [إصلاح يحفظ البكسلات](reports/completion-jpeg/job-storage.json). جودة المشاهد وتغطية كل حالات الواجهة ما زالت تجريبية، ولا تدريب صور منجز.
- [حزمة Windows المحمولة](docs/DESKTOP.md) الأحدث x64 غير موقعة وبلا مثبّت NSIS؛ اجتازت اختبارات الخادم المضمّن وظهرت بوابة الاقتران في WebView2. اختبار المهارات بعد الاقتران وإعادة فتح جلسة النافذة مؤجلان باختيار المستخدم. العمال غير المعبأة تعرض unavailable صراحةً؛ لا تُنقل إليها أدلة تشغيل المصدر تلقائيًا.

## السحابة الاختيارية

الوضع الافتراضي محلي فقط ولا يوجد تحويل تلقائي. **التوليد السحابي معزول مؤقتًا عند بوابة التنفيذ بعد تدقيق Guard**؛ اختيار الهجين أو وجود مفتاح لا يفعّله. أوامر إدارة المفاتيح القائمة تبقى في مخزن النظام:

```powershell
.venv/Scripts/python.exe scripts/set-key.py openai
# أو anthropic أو brave للبحث
```

جلب المصادر العامة والمزامنة الاختيارية لهما إعداداتهما وأذوناتهما المنفصلة؛ ليسا تفويضًا لإرسال ملف خاص إلى نموذج. إعادة فتح التوليد السحابي تتطلب سياسة إطلاق بيانات ووجهة/حساب وميزانية وتحققًا حيًا؛ لم يُجر ذلك. لا تدخل المفاتيح في المحادثات أو الملفات أو وسيطات الطرفية.

.venv/Scripts/python.exe -m pytest -q

.venv/Scripts/python.exe scripts/offline_restart_test.py
npm --prefix frontend run build

اختبار النموذج الحقيقي يتطلب تشغيل الخدمة وOllama والاقتران الجديد. بعض سكربتات smoke القديمة سبقت الجلسات وتحتاج تكييفًا؛ رفض401 منها ليس إذنًا لتعطيل المصادقة. اختبار الجولة الحالية هو `node frontend/scripts/guard-ui.mjs` على **خدمة بقاعدة اصطناعية منفصلة** و`RIWAQ_DATA_DIR` مطابق؛ لا تشغله على بيانات العمل. اختبارات الوحدة المؤقتة لا تمس بيانات المستخدم. لا تُعد محاكاة المزود إثباتًا لنجاح النموذج.

راجع [البنية](docs/ARCHITECTURE.md)، [سطح المكتب](docs/DESKTOP.md)، ومسار [التخصيص](training/README.md). لا توجد حزمة macOS أو Linux مختبرة.

## تشغيل المعرفة العامة

على هذا الجهاز، `scripts/start.ps1` يضبط نموذج التضمينات المثبت. على جهاز جديد اختَر نموذجًا محليًا مسموحًا بميزانية التنزيل واضبط `RIWAQ_EMBED_MODEL`؛ الإعداد المستخدم هنا `embeddinggemma-2:270m-q8_0-text`. لا ينزّله التطبيق تلقائيًا. غيابه يتيح البحث النصي BM25 مع إظهار المحرك المستخدم. تبقى أوزان نموذج الإجابة مستقلة عن الفهرسة.

راجع [دليل المعرفة والتحديث والنسخ الاحتياطي](docs/KNOWLEDGE.md)، و[سجل المصادر](knowledge/sources.json)، و[حالة التنفيذ](PROJECT_STATE.md). الدفعة الفعلية صغيرة: وثائق برمجة وصفحة علمية عن الماء، وليست معرفة موسوعية شاملة.

لنسخة SQLite متسقة تشمل المحادثات والفهرس دون أسرار مخزن النظام:

```powershell
.venv/Scripts/python.exe scripts/backup_local.py --output D:/RiwaqBackups/backup-2026-11-12/riwaq.sqlite3
```

اختر اسمًا جديدًا لكل نسخة. هذه نسخة صيانة SQLite وليست مسارًا لتجاوز مراجعة صلاحيات الاستعادة. بعد Guard، استخدم [النسخ المشفر والاستعادة إلى حجر](docs/RIWAQ_GUARD.md#الاستعادة-المشفرة-إلى-حجر) لإجراء الاستعادة المدعوم؛ لا تشغّل قاعدة قديمة مباشرةً كبيانات نشطة ولا تحذف علامة الحجر. يبقى الأصل محفوظًا، والنماذج ومفاتيح مخزن النظام تُدار منفصلة. النسخ الخفيفة JSON لا تشمل أصول المستندات ومعايناتها أو كل الوسائط.
