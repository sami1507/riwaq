Riwaq identity-v2, selected direction B: open arcade / asymmetric inward return.
Canonical symbol geometry: ../../src/brand-geometry.json (from this folder).
Arabic and Latin lettering uses actual browser-shaped IBM Plex glyph positions,
exported as native editable SVG paths. The wordmark is typography based on IBM
Plex Sans Arabic SemiBold, not a newly invented font or joined calligraphy.
See ../fonts/plex-sans-arabic-LICENSE.txt and ../fonts/plex-sans-LICENSE.txt.
riwaq-wordmark-* retains the existing combined symbol+Arabic canvas for compatibility;
riwaq-lockup-* is an explicit alias, riwaq-lettering-* is Arabic lettering only,
and riwaq-bilingual-* adds the subordinate Riwaq line. White/black are one-color
reversed/positive assets. All SVG marks are passive paths, without raster images.
icon-*.png are ivory rounded application badges. icon-transparent-*.png are
transparent green symbols. 16/24/32/48/64/128/256px are generated from the same
canonical SVG. Desktop ICO uses 32px first, with all seven size frames.
Build guide and font provenance: reports/identity-20261116/asset-audit.md at repo root.
Regenerate icons: node scripts/identity_icon_export.mjs from the repository root.
