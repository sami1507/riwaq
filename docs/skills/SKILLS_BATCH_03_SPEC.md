# الدفعة الثالثة — العقود والتكامل

نسخة التنفيذ: 2026-11-16، السجل 3.0.0. مرجع الحالة والاعتماد الوحيد لهذه الدفعة هو [مصفوفة القبول](SKILLS_BATCH_03_ACCEPTANCE.md). وجود التعريف لا يعني اعتماد جميع خصائص الطلب الأصلي.

## خط الأساس والبنية

المستودع الموجود React 19.2 / TypeScript 5.9 / Vite 7.2 وFastAPI/Pydantic 2.14 وSQLite على Windows المستخدم. Node 24.19.0 وPython 3.12.10. لم يوجد مجلد Git أو AGENTS.md. حُفظت 419 نسخة ملف قبل التغيير، 4,913,295 بايت، في `reports/skills-batch-03-20261116/baseline` مع بيان بصمات. اجتاز خط الأساس المحلي 92 اختبارًا في 8.01 ثانية. لا مقارنة زمنية بين مجموعة الأساس الصغيرة والمجموعة الشاملة.

الهوية والواجهة والخادم ومخزن الملفات بقيت كما هي. تستخدم المهارات الجديدة `skill_runs` وGuard والجلسة المحلية الحالية والميزانية ونقاط الاستئناف وتسليم `skill_artifacts`. لا نظام حسابات أو تخزين معرفة أو متصفح موازٍ. التثبيت المحلي يملك مالكًا محليًا؛ اختبارات فصل المشاريع والهوية الاصطناعية لا تثبت منصة SaaS متعددة المؤسسات.

## مسار التنفيذ

رسالة أو اختيار عربي للعملية ← `SkillRequest` متحقق ← اختيار حزمة محددة وبصمتها ← فحص مصادرها وإصداراتها وGuard ← حجز خطوة ← `skill_batch03.run` ← العامل الثابت أو خدمة الملفات أو موصل الموقع المسجل ← فحص العقد والأثر ← الحفظ وإعادة التفويض ← رابط تنزيل محمي.

`SkillInputs` أضيفت إليه `sourceRefs` و`outputVersion` و`documentOperation` و`dataOperation` و`webOperation` و`folderOperation` و`versionOperation`. لا هوية موثوقة في هذه المدخلات؛ المالك والجلسة من الخادم. يُرفض تعارض المهارة مع العملية أو المصادر قبل تشغيل الأداة. مدخل العمليات المعقدة لا يستنتج حقولًا شخصية أو وجهات إرسال مفقودة من النموذج.

مرجع المصدر: `{kind: document|artifact, id, version, sha256, pinned}`. المرجع غير المثبت يرفض تغير النسخة أثناء المهمة؛ المثبت يقرأ نسخة محددة مع صلاحياتها الحالية. يحفظ إيصال العامل SHA للمصدر وللطلب والمخرجات. stdout لا يمنح نجاحًا بمفرده؛ يلزم عقد JSON مطابق وإيصال المشرف وفحص سياسة التشغيل ورمز الخروج والتنظيف وإعادة التفويض. المحتوى المستخرج يبقى بيانات.

العامل `skill_transform` امتداد لنفس `isolated_worker`، بصورة Linux محلية مثبتة، بلا شبكة أو تركيب مجلد المضيف، وبمدخل stdin محدود. لا fallback إلى تنفيذ المضيف أو سحابة. الحدود: حتى 8 مصادر، 8 MiB مجموع محتواها، 8 MiB مجموع المخرجات، 13 MiB غلاف نقل، 90 ثانية للعامل، 1024 MiB ذاكرة، و180 ثانية للمهمة. يظل حد الطلب HTTP هو 200,000 بايت و8 خطوات. Excel/CSV: حتى 1000 صف و26 عمودًا و20,000 خلية. هذه حدود فعلية وليست دعمًا غير محدود.

## الملفات والإصدارات

`skill_file_heads` و`skill_file_versions` و`skill_folder_operations` جداول إضافية تربط نفس BLOB المحفوظ؛ لا نسخ تخزين موازية. الترحيل عند بدء الخدمة يسند هوية للمخرجات القديمة دون نسخ بايتاتها. حد المشروع 200 ملف نتيجة، و20 نسخة لكل ملف، وسقف `skill_artifacts` القائم 64 MiB؛ بلوغ الحد يرفض ولا يمحو التاريخ صامتًا.

التحديث يتطلب النسخة الحالية المتوقعة ونفس MIME. يتغير رأس الملف في معاملة النشر النهائي فقط؛ الإلغاء أو الفشل السابق لها يبقي الأصل. الاسترجاع ينشئ نسخة جديدة، ولا يمحو الأحدث. حذف النسخة الحالية لا يعيد نسخة قديمة تلقائيًا. صلاحيات كل أصل تبقى مطبقة على المشتق وروابط النسخ. تنظيم المجلدات هنا تنظيم منطقي لمخرجات المشروع؛ لا نقل لأقراص المستخدم أو تغيير مشاركة مزود خارجي. المعاينة تحمل بصمة وخطة قبل/بعد، والتطبيق والتراجع يفحصان التنازع والأسماء مرة أخرى.

## واجهات وتجهيزات

`GET /api/projects/{pid}/skill-files`، وقائمة النسخ، ورابط أحدث نسخة، و`/versions/{n}/download`. التعديل والتنظيم والاسترجاع تمر عبر `POST .../skill-runs` نفسه. لا روابط عامة. واجهة `SkillTransforms` تختار العملية والمصادر والخيارات؛ التقارير الهندسية مطوية. يمكن استخدام نتائج محفوظة كمدخل للمهمة التالية دون إعادة رفعها. العمليات المتعددة المعقدة تحتاج خطوات صريحة؛ لا ادعاء تنفيذ سلسلة تحويل كاملة تلقائيًا من وصف حر واحد.

الويب لا يرسل في وضع «تعبئة فقط». `submit=true` يحتاج بصمة الصفحة ووجهة مطابقة لعنصر `web_form_targets` في المصدر المعتمد. جدول `skill_web_submissions` يمنع تكرار الطلب ويحتفظ بالحالة المجهولة عند فقد الرد. لا إعادة إرسال تلقائية، ولا اعتبار رسالة SUCCESS في HTML إثباتًا.

## تراخيص وإعادة استخدام

تعريفات المهارات مكتوبة للمشروع، ولم تُنسخ سكربتات من حزم خارجية. استُخدمت صيغة Agent Skills للحقليْن `name` و`description` فقط؛ الحالة والمخططات والحدود في سجل رواق. مراجع المواصفة: https://agentskills.io/specification وhttps://agentskills.io/client-implementation/adding-skills-support .

تفاصيل المصدر والإصدار وSHA والترخيص في `reports/skills-batch-03-20261116/documents/pdf-dependency-acquisition.json` وبيان سياق الصورة. حزم التحويل الجديدة داخل الصورة فقط: fpdf2/LGPL-3.0-only، fonttools/MIT، uharfbuzz/Apache-2.0، Brotli/MIT وفق ملفات التوزيع. pypdf/BSD-3-Clause والخطوط IBM Plex/OFL من أصول المشروع مع نصوص تراخيصها. لا تثبيت مكتبات جديدة على Python المضيف. يلزم استيفاء التزامات LGPL عند توزيع الصورة خارج هذا العمل؛ لم يحدث نشر هنا. محرك `@oai/artifact-tool 2.8.157` استُخدم للتحقق المستقل فقط، وليس اعتمادًا للمنتج.
