# الدفعة الخامسة — أساس تشغيل المهارات 101–125

تاريخ المواصفات والتحقق المحلي: 16 نوفمبر 2026. توسعة للمشروع القائم React/TypeScript/Vite وFastAPI/Pydantic/SQLite على Windows. لم يوجد Git أو AGENTS.md في مساحة العمل. حُفظ خط أساس من 604 ملفات قبل التغيير، ولم تختلف ملفات المصدر المشتركة عن بصمة تسليم Batch04. لا إطار أو حسابات أو مجدول أو قاعدة معرفة بديلة، ولا نشر أو إرسال خارجي ضمن هذا التكليف.

السجل المرجعي يبقى [config/skills-batch-01.json](../../config/skills-batch-01.json) باسمه التاريخي؛ الإصدار 5.0.0 يضم 125 تعريفًا، مع بقاء سجلات أول 100 دون تغيير. التعريف ليس اعتمادًا. بعض مهام 101–125 ضوابط تعمل تلقائيًا داخل النظام، وأزرارها تعطي فحصًا للضابط ولا تشغّل اختبارًا أو استعادة أو ترقية من نص النموذج. الحكم التفصيلي في [ACCEPTANCE](SKILLS_BATCH_05_ACCEPTANCE.md)، والتجربة والإعداد والرجوع في [REPORT](SKILLS_BATCH_05_REPORT.md).

## مسارات التكامل

1. تعريفات الاكتشاف ← `skill_registry.validate_catalog` ← التوجيه وحل الاعتماديات ← قراءة الحزم المختارة فقط. الاسم والإصدار والوصف والأدوات والقيود التطبيقية مصدرها السجل؛ SKILL.md يحمل التعليمات دون منح إذن أو تنفيذ سكربت.
2. طلب مصرح ← `SkillRequest` وGuard ← ترتيب المهارات ← بوابة الإصدار إن اشترطها التعريف ← تثبيت `package_pin` قبل الإرسال إلى عامل المهام. يحمل المثبّت تعليمات/مراجع الحزمة فقط؛ لا ملفات المستخدم أو أسراره. يقرأ المستخدم ملخص الإصدارات والبصمات.
3. إنشاء المهمة ← مهلة كلية محفوظة تشمل الطابور ← حجز قائم في SQLite ← انتقالات موثوقة وإيصالات ← فحص النسخة والصلاحية والمهلة قبل حفظ المخرج. الإلغاء المطلوب يحتفظ بمقعد التزامن حتى إقرار توقف العامل.
4. توليد Ollama ← هوية نموذج مثبت ومعلومات قدرة حديثة ← ميزانية مدخلات/مخرجات ← قبول منظم للسعة وإعادة محاولة/بديل محلي محددين ← تحقق الاستجابة والعقد ← بث وحفظ. لا يظهر JSON غير متحقق ثم يُسحب بعد ذلك.
5. أحداث تنفيذ محددة الحقول ← `guard_audit` القائم ← عرض محمي بنطاق المشروع. صحة الخدمة تجمع أحداث المهمة وSQLite ونشاط عامل التذكير، ولا تستنتج النجاح من HTTP200 وحده.
6. مشغل اختبارات ثابت محلي ← pytest/تقييم/فحص واجهة بحسب الملف المختار ← تقرير حالات ومصدر وبيئة ← إيصال موقع بمفتاح التثبيت المحمي. لا endpoint يوقع تقريرًا يقدمه النموذج. الاعتماد المحلي لا يجيز نشرًا أو يمنح اعتماد مزود حي.

## العقود والحدود المشتركة

الهوية والجلسة والمشروع من السياق الموثوق. `systemOperation` عقد Pydantic للفحص فقط؛ يرفض خلط فحص نظام بعملية بريد/تقويم/ملف ذات أثر. لا يُنفذ أمر shell أو مصدر اختبار أو نموذج من نص حر يقدمه المستخدم. تفاصيل الضوابط المطولة موزعة في [ملاحظات السجل](BATCH05_REGISTRY_NOTES.md)، [المزودات](BATCH05_PROVIDERS_NOTES.md)، [التشغيل والتعافي](BATCH05_OPS_NOTES.md).

الاكتشاف يفصل installed/enabled/ready/tested. ready هنا توفر المعالج والاعتماديات المعلنة ضمن نطاقه، ويعاد فحص مورد العملية ووجهتها عند التنفيذ؛ لا يثبت جودة لغوية أو أمانًا عامًا. قدرات مجهولة أو مرجع تغير أو اعتماد إلزامي مفقود لا تتحول إلى جاهزية. optional لا يجيز نقل بيانات إلى سحابة. إصدارات الاعتماد تدعم صيغة عددية محدودة وقيود مقارنة موثقة، لا كل صيغ npm أو PEP440.

مثبّت الحزمة محدود بـ14000 محرف وبثماني مهارات نشطة بعد توسيع الاعتماديات. تبقى النسخة المثبتة خلال ترقية متوافقة؛ سحبها أو تغير عقد أدواتها/بياناتها/وجهاتها أو إعادة استخدام الإصدار ببصمة مختلفة يمنع المتابعة. هذه سياسة محافظة وليست ترحيل تعليمات تلقائيًا. البصمة تكشف تغير المحتوى؛ لا تصدّق الناشر وحدها. يمكن تجهيز مدخلات قدرة مثبتة ومفعلة قبل أن تصبح جاهزة للمهمة؛ منع التنفيذ الصلب لا يختلط بنقص مدخل قابل للإكمال.

المهلة الكلية الحالية 180 ثانية، ومهمتا مهارات نشطتان كحد قائم. يستمر احتساب الإلغاء من السعة حتى يتوقف العامل. خيط بناء Python لا يقتل قسرًا؛ يبقى المقعد محجوزًا حتى خروجه ويمنع المسار حفظ ناتج متأخر. يعاد فحص السعة عند الاستئناف، ولا يتيح انتهاء lease لعامل قديم تعديل عمل عامل أحدث. المهلة لا تمحو كتابة خارجية ربما تمت؛ حالة unknown وإيصال الأثر يظلان منفصلين. تنظيم مزود Ollama محلي لكل عملية خدمة: حد 2، وطلب نشط لكل مالك وطوابير محدودة وتباعد وcooldown. هذه حدود موارد تطبيقية وليست حصصًا مزعومة للمزود أو عدالة موزعة بين خوادم.

ميزانية السياق تقدير محافظ بالبايت مع احتياطي للقالب والناتج، وليست عدد tokens مفوترًا. يحتفظ البناء بالتعليمات والطلب والتصحيحات والمحادثة الكاملة ضمن الحد، ويختار مقاطع مصدر كاملة مع بيان التغطية. تجاوز الحد يرفض صراحةً ولا يسقط سياقًا لازمًا بصمت. لا تلخيص أفكار داخلية. البديل الافتراضي فارغ، ويقتصر على نماذج Ollama محلية مثبتة اختارها المشغل؛ لا إعادة بعد مخرج محتمل أو أثر مجهول، ولا تحويل سحابي.

النموذج الحي المختبر لهذه الدفعة هو qwen3:4b-instruct مع Ollama 0.40.16، على نص اصطناعي ثابت فقط. النص وJSON المقاسان منفصلان عن معلومات الدعم المعلنة للصور والأدوات والصوت. لا تكلفة نقدية أو وفر مالي مقدر دون بيانات.

المراقبة تعرض حتى 200 مهمة حديثة بنطاق المشروع، ومددًا من timestamps محفوظة؛ p95 لا يظهر قبل 100 عينة. قدم العامل بعد 15 ثانية مبني على ثلاث دورات اسمية كل 5 ثوان، وليس ضمان تسليم. السجل حقول مسموحة، وتعطل كتابته في المعاملة يمنع ادعاء تسجيل ناجح. لا سجل تفكير أو متن بريد؛ الاحتفاظ الحالي مرتبط بقاعدة البيانات المحلية وليس سياسة زمنية جديدة مفروضة.

النسخ يستعمل SQLite backup القائم وDPAPI لمستخدم Windows الحالي، ثم يفحص سلامة البيانات والمراجع وبصمات blobs. تشمل النسخة ملفات مخزنة فعلًا داخل القاعدة؛ مجلدات البرمجة الخارجية وملفات runtime والإعداد التشغيلي ومفاتيح النظام خارجها. الاستعادة إلى مجلد جديد في حجر: جلسات وصلاحيات ومنح إرسال/تذكير قديمة لا تُفعل، والأثر المرسل غير المحسوم يبقى unknown. تسوية الحذف اللاحق وسحب الوصول مطلوبة قبل أي تفعيل؛ لا أمر إزالة الحجر في هذا التكليف.

## البيئة والتراخيص

لا اعتماد جديد أو تنزيل نموذج أو اشتراك. أعيد استخدام Python 3.12.10 وHTTPX 0.28.1 وPydantic الموجود وWindows DPAPI وOllama المثبت. مراجعة API الإصدار الفعلي ومراجع الترخيص الرسمية في ملاحظات المزودات. لم تُوسّع حقوق النموذج المثبت أو تعاد توزيع أوزانه. اختُبرت واجهة المتصفح بالإنجليزية والعربية مع RTL؛ المجموعة النصية للتوجيه تضم العربية والعبرية والإنجليزية. هذه عينات محدودة وليست تقييمًا لكل لغة أو مزود. التغليف وتطبيق Windows بعد الاقتران غير متحققين لهذه الدفعة، وما بعد الاقتران بقي مؤجلًا بطلب المستخدم.
