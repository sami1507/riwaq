# قبول الدفعة الثالثة 51–75

تحديث مرجعي لاحق: الدفعة الرابعة وسعت السجل ومحرك المهام المشترك إلى 100 تعريف مع إبقاء أول 75 سجلًا. نتائج هذه الصفحة تاريخية لنسختها؛ اختبارات التراجع وإعادة مسار البيانات الفعلي الحالي في [قبول الدفعة الرابعة](SKILLS_BATCH_04_ACCEPTANCE.md). لا يُنسب اختبار جديد إلى بيئة قديمة أو العكس.

الحالة بتاريخ 2026-11-16. «جزئية» تعني أن جزءًا حقيقيًا يعمل، مع قيد يمنع اعتماد المواصفات الأوسع. لا يتحول نجاح بنية الملف أو mock إلى اعتماد عرض أو مزود أو منصة. النطاق المشترك: خادم Python على Windows، تخزين SQLite محلي، وعمال Linux داخل Docker Desktop/WSL2. اختبار الواجهة هو Chromium على Windows، وليس نافذة تطبيق Windows الأصلية بعد الاقتران؛ ذلك الاختبار متبقٍ بطلب المستخدم.

**الواجهة بعد آخر إصلاح للصلاحيات:** `ui/2026-11-16T09-10-42.754Z/report.json` — **11 مسارًا فعليًا و1 عقد محاكي** ناجحة، Chrome157 على Windows. لم تُعدّل الواجهة بين هذا التشغيل وسابقه. `metadata-deletion-before.xml` أثبت إخفاق تاريخ الملف ومعاينة التنظيم بعد حذف المصدر؛ `metadata-deletion-after.xml` اجتاز93حالة مرتبطة بعد الإصلاح، ثم أُعيد الفحص الشامل المذكور أعلاه.

## حدود اعتماد مشتركة

لا إصلاحات دلالية عبر نموذج في عمليات الحساب أو استخراج OOXML. العربية والعبرية والإنجليزية اختُبرت كنصوص/أسماء/قيم وعينات PDF؛ ذلك لا يثبت كل لهجة أو خط أو ترتيب نص مختلط. فحص الجداول مستقل عن OCR. نسخة سطح المكتب المحمولة السابقة لا تحتوي هذه التغييرات، والعامل الجديد يرفض التشغيل المجمّد غير المهيأ بدل الادعاء بأنه يعمل.

جميع 25 تعريفًا لها مدخل وتوجيه ومكون تشغيل، لكن بعض المسارات تحتاج خيارات منظمة أو خطوات منفصلة، ولا توجد دعوى بأن أي وصف حر مركب يُنجز تلقائيًا بلا توضيح. بقيت حماية الذاكرة الشخصية والتوليد السحابي وإعدادات المستخدم كما كانت. لا إرسال مستندات خاصة لخدمة خارجية ولا تغيير أسرار.
