# عوائق نواة رواق وحدود قبولها

هذه قائمة فجوات تمنع تعميم الاعتماد، ولا توقف تطوير واختبار المسارات المستقلة.
تُحدث نتيجة الجولة الحالية بعد تجميد الشيفرة؛ لا تُستعار نتيجة من دفعة أقدم.

| الفجوة | ما لا تثبته الأدلة المحلية وحدها | خطوة الاستئناف المحددة |
|---|---|---|
| المعنى والاستدلال وجودة الصياغة | مطابقة JSON أو الكلمات أو الأرقام ليست حكمًا دلاليًا شاملاً | تشغيل عينة حيّة موثقة على المزود المحلي المهيأ ثم مراجعة مستقلة وفق المعايير، وحفظ كل الإخفاقات دون تغيير الأجوبة المرجعية |
| تصحيح مسودة مسندة في المحادثة العادية | إعادة التصحيح المحدودة أنجزت2/3حالات جديدة؛ الثالثة بقيت اقتباسات مطابقة جزئية دون ادعاء اكتمال التصحيح | تحسين جودة التصحيح على عينة تطوير ذات إصدار ثم فحص عينة جديدة؛ الحفاظ على فحص الاقتباس والوحدة وعدم إضعافه لجعل النتيجة ناجحة. التفاصيل في [ملاحظات الدليل](AI_CORE_EVIDENCE_NOTES.md) |
| تعميم نتيجة العينة على جميع الأفراد | الحالة المنطقية الخامسة بقيت جزئية قبل السياسة وبعدها، رغم صحة رفض التعميم في أول الإجابة | إصلاح الاستنتاج الزائد وفحصه بمعايير مستقلة؛ لا ادعاء تحسن من إضافة تعليمة فقط. التفاصيل في [ملاحظات الاستدلال](AI_CORE_REASONING_NOTES.md) |
| المعايير الفرعية غير المنفذة من الحالات الحالية | المرجع المختصر يلخص الطلب المتاح، ونجاح الجزء المحدد لا يثبت جميع شروط الحالة | تنفيذ الشروط الباقية في عينة مستقلة واضحة، مع إبقاء الحالة جزئية حتى التحقق منها دون تغيير معيار النجاح |
| مخطط مصور وصوت ملتبس وOCR عربي | قراءة واضحة اصطناعية أو mock لا يثبت لهجة بشرية أو اسمًا ملتبسًا أو ترتيب أعمدة | توفير fixture اصطناعي مرجعي لكل حالة، تشغيل المحرك الفعلي ثم مراجعة الصوت/الصورة والمواضع المطلوبة |
| عرض Word وExcel والرسوم الأصلي | سلامة OOXML والصيغ والـcache لا تثبت التخطيط في العارض الأصلي | Word/Excel مثبتان لكن تشغيل COM تعذر، وLibreOffice غائب. العارض البديل تحقق من الرسم والصفر وتعديل31؛ يبقى إصلاح تشغيل العارض الأصلي ثم قبول الصفحات والحدود بصريًا |
| إعادة مشتقات بعد تصحيح أو تغيير لغة | تعديل لغة السرد وجداول Word من التحليل المحفوظ مثبت ضمن حدوده؛ تحديث جميع المشتقات بعد تغيير المصدر غير مثبت | ربط إصدارات التبعيات ثم سيناريو تعديل أثناء المهمة وفحص كل أثر محفوظ قبل التسليم |
| استمرار المهمة بعد أثر خارجي مجهول | الإيصال المحلي أو إلغاء الانتظار لا يثبت أن المزود لم ينفذ الأثر | استخدام استعلام أثر أو معرف مزود في حساب اختبار مصرح؛ إبقاء الحالة مجهولة إذا تعذر الحسم |
| اختبار نافذة Windows بعد الاقتران | اختبار خادم أو Chromium ليس هذا الاختبار | مؤجل باختيار المستخدم؛ لا إعادة طلب الاقتران ضمن هذه الجولة بلا تغيير منه |
| الحزمة الموزعة والعمال | تشغيل المصدر لا يثبت أن أحدث عامل موجود داخل حزمة منشورة | بناء مستقل مصرح للحزمة، تثبيت البصمة ثم فحص HTTP والنافذة والعمال المعنيين |
| مزودات خارجية ورسوم وإرسال حقيقي | نجاح المحاكاة لا يثبت اتصالًا أو تسليمًا أو قراءة لدى مزود | إعداد اعتماد الحساب في مخزن أسرار النظام، وتحديد حسابات وموارد اختبار؛ لا أسرار في المحادثة ولا إرسال إنتاجي |
| الأمن الأوسع والذاكرة الشخصية | اختبارات العزل المحددة ليست شهادة أمان مطلق | إبقاء بوابة الذاكرة الشخصية والمراجعة الأمنية الحالية، وإكمال العزل والمراجعة المستقلة حسب سجل المنتج |
| المقارنة والزمن والتكلفة | عينة واحدة أو زيادة عدد الاستدعاءات لا تثبت تحسنًا | نفس الحالات والمزود والنموذج والإعدادات وحدود الميزانية، ثم مقارنة أعداد نجاح/فشل وزمن واستهلاك فعلية |

لإعادة فحص مجموعة الحالات الحالية:

```powershell
.venv/Scripts/python.exe -m pytest tests/test_ai_core_evaluation.py -q
.venv/Scripts/python.exe scripts/run_ai_core_evaluation.py --output reports/ai-core-20261116/new-evaluation
.venv/Scripts/python.exe scripts/run_skill_regression.py --ci --ai-core --no-seal --output reports/ai-core-20261116/new-ci
```

يجب أن يكون مجلد الناتج جديدًا. أداة التقييم المستقلة تعيد0 عند نجاح المعايير
في نطاقها المسجل، و1 للفشل، و2 للدليل الجزئي أو المتعذر. أمر CI يعيد2 للحالة
الجزئية، و1 للفشل أو التعذر؛ ولا يعيد0 إلا عند استيفاء بوابته. لا يعني رمز
الخروج غير الصفري حذف الأجزاء الصحيحة، ولا تتحول الحالات الجزئية إلى نجاح. اقرأ
`AI_CORE_EVAL_RESULTS.json` وحالاته وبصمته ومجالاته غير المختبرة قبل أي اعتماد.
