## التغييرات المثبتة

- يحفظ الخادم سبب انتهاء المزود ويصنّف بلوغ حد التوليد أو توقفًا غير طبيعي بأنه interrupted، مع حفظ النص الجزئي. الرد الفارغ ليس نجاحًا. تعرض الواجهة حالة «رد غير مكتمل» عند إعادة الفتح.
- تظهر ملاحظة من بيانات الرسالة المحفوظة عندما لا يربط النموذج رده بأي معرّف مقطع صالح. وجود معرّف صالح لا يثبت دعم كل ادعاء.
- يُفحص نموذج Ollama فعليًا عبر api/show قبل عرضه كنموذج محادثة. لا يُختار نموذج التضمين عند التحويل إلى الوضع المحلي. تُغلق مسارات Enter وإعادة المحاولة والتفرع عندما لا يكون النموذج جاهزًا، وتبقى مسودة السؤال عند رفض الطلب قبل بدء البث.
- تُراجع صلاحيات المصادر وإصدارات المقاطع بعد انتظار التحقق من المزود وقبل إرسال السياق. اختبرت حالات تعليق المصدر وحذفه وتغيير نسخته أثناء الانتظار.
- تُحسب ميزانية السؤال والتعليمات والذاكرة والمقاطع والتاريخ قبل حفظ الطلب. تُختار مقاطع كاملة، ولا يُقص السؤال بصمت. الحساب ببايتات UTF-8 مع احتياط للقالب محافظ للنموذج المحلي، وليس عداد رموز عام لكل مزود.
- استخراج HTML يحتفظ الآن بمسافات المسافة البادئة والأسطر الفارغة داخل pre، ويستخدم سياجًا للشيفرة ويُبقي فواصل خلايا الجداول. يحتفظ النظام بالمستخرج القديم لإعادة التحقق من الإصدارات السابقة.
- أصبح extractor جزءًا من بيانات المعالجة وإسناد النسخ؛ النسخ القديمة دون الحقل تُفسَّر legacy-v1. إعادة المعالجة تحفظ معلمات التقسيم التاريخية ونسخة المكتبة، حتى لو تغير سجل المصدر لاحقًا.

راجعت التنفيذ وفق [توثيق انتهاء بث Ollama](https://docs.ollama.com/api/chat) و[بطاقة النموذج المستخدمة](https://huggingface.co/Qwen/Qwen3-4B-Instruct-2507). لم تُنزّل أوزان جديدة أو يُجرَ تدريب.

## التحقق من المسار الكامل

القصة المختبرة: سؤال من واجهة المحادثة ← API ← مصادر محفوظة ونموذج Ollama محلي ← بث الرد والمراجع ← SQLite ← إعادة فتح المحادثة.

| الحد الفاصل | النتيجة والدليل |
|---|---|
| الواجهة والإعدادات | فحص AR/EN لاختيار النموذج وحالات الانقطاع والمراجع والمسودة؛ جميع API في هذا الفحص وحده مصطنعة ومحجوبة عن البيانات الحقيقية |
| API والتخزين | 32/32 إجابة مقارنة حُفظت واستُعيدت مطابقة داخل نسخة مؤقتة |
| المزود الحقيقي | اختبار مستقل بحد32 رمزًا انتهى بسبب length وحُفظ interrupted بدل complete |
| المتصفح والنموذج | سؤال FastAPI فعلي أجاب Pydantic مع [S2]؛ لوحظ النص أثناء البث واستُعيد العرض مطابقًا بعد إعادة تحميل الصفحة |
| الهاتف | فُحصت المحادثة المحفوظة من صفحة جديدة بمقاس390×844، دون تمرير أفقي، والقائمة المغلقة خارج الشاشة مع نجاح فتحها وإغلاقها |
| الشبكة | حارس عملية التقييم رصد196 تحقق loopback وحظر الوجهة الخارجية الاختبارية؛ لم يحاول إرسال بيانات إلى مزود خارجي |

اختبارات Python النهائية: **186 ناجحة، واحد متجاوز** لامتياز رابط Windows، وتحذير إهمال واحد من pypdf. بناء TypeScript/Vite نجح؛ بقي تنبيه حجم حزمة JavaScript فوق500KB.

فحص الواجهة المصطنع دليل لسلوك الواجهة فقط. المحادثة الفعلية موثقة منفصلة في [grounding-live-browser.json](../reports/grounding-live-browser.json). لم تُفصل شبكة الجهاز ولم تُعزل عملية Ollama بجدار حماية؛ حارس Python لا يثبت عزلًا على مستوى النظام.
