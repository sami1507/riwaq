# قرارات نواة رواق — 16 نوفمبر 2026

1. **توسعة المنتج نفسه.** تُستخدم FastAPI وSQLite ومحرك المهام والمزودات
   والعزل والتسليم القائمون. لا مخزن معرفة أو صندوق أدوات أو نظام حسابات بديل.
   أول125 تعريفًا يبقى سجل مهارات المنتج؛ ترقيم AI-01–AI-20 هو محاور تقييم
   لهذا التكليف، وليس إضافة أسماء مهارات لمجرد رفع العدد.

2. **الطلب عقد قابل للفحص.** يربط القيد والمخرج والمرجع بالطلب الحالي، وتُرفض
   القيود المتناقضة قبل الأثر. وجود قيد مستخرج لا يثبت تلقائيًا صحة كل صياغة
   مولدة؛ يبقى فحص المخرج منفصلًا.

3. **البيانات ليست أوامر.** المستند والخلية ورسالة البريد والاقتباس لا تمنح
   إذن حذف أو إرسال أو انتقال سحابي. السلطة من الجلسة وسياسة الخادم.

4. **الحساب بمحرك، لا بتخمين.** تُستخدم العمليات الحتمية الموجودة للأعداد
   والنسب والوحدات والجداول. التطبيع العددي صريح للعمود الكمي؛ لا تُزال الأصفار
   أو تُطبّع هوية نصية بلا عقد. ما لا يمثله المحرك بدقة يُرفض أو يبقى معلنًا.

5. **المصدر والموضع أساس الدليل.** لا يكفي وجود الرقم في موضع بعيد من الوثيقة
   لتصحيح اقتباس لا يحمله. تغطية المرشحات المسترجعة ليست قراءة كاملة للمصدر.
   جمع جدول كامل من مقتطف ناقص يجب أن يعلن النقص أو يقرأ النطاق الصحيح.

6. **حقيقة الأثر محفوظة.** الإلغاء لا يعكس رسالة وصلت إلى ناقل أو ملفًا نُشر
   خارجيًا. الاستئناف يعيد فحص الهوية والإصدار والأثر، ولا يعيد كتابة مجهولة
   تلقائيًا. انقضاء المهلة ليس معيار نجاح.

7. **إبقاء بوابات المنتج.** لا سحابة بديلة ضمن معالجة محلية، ولا فتح للذاكرة
   الشخصية، ولا إرسال إلى حسابات المستخدم لمجرد تطوير الميزة، ولا نشر منتج.
   اختبار نافذة Windows بعد الاقتران يبقى مؤجلًا حسب اختيار المستخدم السابق.

8. **تقييم قابل للإعادة.** الحالات المئة معروفة للمطور ولا تسمى محجوزة.
   العينة الجديدة المنفصلة ذات12 حالة حتمية جُمّدت قبل هذه الإضافة وبصمتها
   محفوظة؛ المطور يستطيع رؤيتها، لذلك ليست اختبارًا أعمى. نتيجة خط أساسها
   لا تدل على تحسن ما لم تقارن بالشروط نفسها.

9. **حالة لكل معيار.** أمر التقييم يشغّل اختبارات محددة حديثًا ويقرأ XML الذي
   أنتجه في مجلد جديد. يميز `passed` و`failed` و`partial` و`blocked` و`skipped`
   و`not_applicable`. اختبار مكوّن مقارب فقط يمنح دليلًا جزئيًا، وفحص بنية رسم
   أو ملف لا يمنح قبول عرض أو جودة لغوية. فشل حرج لا يختفي داخل متوسط.

10. **بصمات وإعدادات دون أسرار.** يحفظ التقرير بصمة الشيفرة ومجموعة الحالات
    والتكوين، وإصدارات Python والمنصة ونوع الاختبار. لا يقبل أمر التقييم تقريرًا
    قديمًا أو نص PASS بوصفه تشغيلًا جديدًا، ولا يفعّل مهارة أو يوقع قرار نشر.

11. **التراخيص والاعتماديات.** إعادة استخدام الاعتماديات المرخصة المثبتة
    ومراجعها الحالية؛ لا تنزيل نموذج أو تثبيت مزود مدفوع لهذه الحزمة تلقائيًا.
    أي صورة عامل يعاد بناؤها تحتفظ ببصمة النسخة وسجل التحقق الفعلي.

12. **المراجع غير المتاحة معلنة.** لم يُعثر على ملفات تكليف TECH مستقلة في
    المستودع المفحوص. لا يُختلق ربطها أو اعتماد225 مهارة. طلب الحالات الحالي
    متاح ومرجعه المختصر وبصمته مسجلان؛ المعايير الفرعية التي لم تُنفذ تبقى غير مثبتة.

لا ترحيل مدمرًا يفرضه إطار التقييم. ملفات التقرير جديدة، وسجل الاختبارات
القديم محفوظ بتاريخ نسخته. التشغيل لا يمس بيانات الاستخدام اليومية.
