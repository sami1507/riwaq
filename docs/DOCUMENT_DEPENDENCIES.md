# اعتماديات المستندات المحلية

آخر تحديث: 15 نوفمبر 2026. يصف هذا الملف عامل `document_page` المعزول الحالي، ثم يحفظ ملخص إعداد Windows السابق بوصفه دليلًا تاريخيًا. لم تُغيَّر CUDA أو أوزان النماذج، ولم يُنفذ تدريب أو استدعاء مدفوع. غياب الصورة أو محرك Docker أو فشل التحقق يمنع استخراج المستند؛ لا تنزيل تلقائي ولا رجوع إلى عامل المضيف.

## المسار الحالي والاعتماديات الفعلية

يتلقى العامل بايتات الأصل واسمًا أصليًا محدودًا ورقم الصفحة واللغات والحدود عبر stdin. لا يتلقى مسارًا على المضيف أو أمرًا من المستند. يشغّل `scripts/isolated_document_worker.py` المحلل الحالي `backend/document_extract.py` نفسه، ويشغّل OCR عبر غلاف Node الثابت. النتيجة نص منظم ومعاينة PNG محدودة، مع البصمات وهوية المصدر. Office يُقرأ من XML محدود؛ لا حاجة إلى نسخ openpyxl أو python-pptx أو lxml إلى الصورة الحالية.

مسارات Tesseract واللغات ثابتة داخل الصورة؛ توضح [واجهة Tesseract.js](https://github.com/naptha/tesseract.js/blob/master/docs/api.md) خيارات العامل واللغات والمحرك. تستخدم [tessdata_fast](https://github.com/tesseract-ocr/tessdata_fast) هنا مع LSTM/OEM1 وPSM3؛ لا تنزيل أو تدريب أو تصحيح نص تلقائي أثناء الطلب.

بعد القبول، فُعّل نفس الإعداد المثبت في `data/isolated-workers.json` لهذا الحاسوب مع نسخة رجوع؛ [سجل التفعيل](../reports/resume-isolation-activation.json). لا يُنقل إلى جهاز آخر دون تحقق مسار العميل وبصمته وهوية المحرك. لم تُعدّل قاعدة المستخدم أو إعداد الذاكرة.

## التشغيل والتكوين

ملف الخادم الموثوق هو `<RIWAQ_DATA_DIR>/isolated-workers.json`. يقبل مخططه الصور الثلاث القديمة، لكن `document_page` يبقى غير متاح حتى إضافة صورته. توجد نسخة قبول مرشحة في `reports/document-isolation-candidate/isolated-workers.json`؛ لا تستعملها كإعداد عام قابل للنقل دون مراجعة مسار Docker وبصمته وهوية محركه المحلي. بيانات هذه الحقول لا تأتي من الملف المرفوع أو المتصفح.

اختُبر Docker Engine 29.9.3 Linux/amd64 عبر WSL2. يتحقق التنفيذ من بصمة CLI، وهوية daemon، ومعرّف الصورة المحلي وسياسة الحاوية الفعلية قبل إرسال الأصل. تقرير الإمكانات يعلن configured وexperimental؛ لا يبدأ عملية أو يفحص daemon حيًا، ولا يجعل `tested=true` لمجرد وجود إعداد. حزمة سطح المكتب المجمدة تبقى `packaged_worker_unavailable` في هذا المسار.

بعد تجهيز الصورة واعتماد الإعداد المحلي، يمكن إعادة القبول دون خدمة ويب أو نموذج:

```powershell
.venv/Scripts/python.exe -X utf8 -B scripts/document_isolation_validate.py --config reports/document-isolation-candidate/isolated-workers.json --output reports/document-isolation-recheck.json
```

للتكامل الحقيقي، انسخ الإعداد للاختبارات عبر المتغير الصريح؛ تتولى fixtures نسخَه إلى مجلدات بيانات مؤقتة:

```powershell
$env:RIWAQ_TEST_ISOLATED_CONFIG=(Resolve-Path 'reports/document-isolation-candidate/isolated-workers.json').Path
.venv/Scripts/python.exe -X utf8 -B -m pytest tests/test_document_isolation.py tests/test_document_isolation_lifecycle.py tests/test_documents.py tests/test_document_vision.py tests/test_document_snapshots.py -q
```

غياب المتغير يتسبب في تخطي اختبار التكامل الحقيقي بسبب واضح، ولا يسمح باستخدام عامل المضيف. اختبارات البروتوكول وسباقات التخزين التي تحاكي النتائج موسومة بصورة مستقلة.

## حدود العامل والثقة

تُطبق حدود 8 MiB للمدخل، 200 صفحة، 8 ملايين بكسل، 2 MiB للنتيجة المنظمة، و8 MiB للمعاينة. غلاف JSON/base64 لا يتجاوز 13,347,500 بايت. وقت فحص الرفع 30 ثانية ووقت الصفحة 90 ثانية، بما فيه انتظار الإرسال، بحد انتظار أقصاه 30 ثانية. للملف مهمة إجمالية محدودة قابلة للاستئناف الصريح.

الحاوية بلا شبكة أو mounts للمضيف، بجذر للقراءة فقط ومستخدم `65534:65534`، مع إسقاط capabilities وno-new-privileges، CPU واحد و64 عملية وذاكرة 2 GiB بلا swap إضافي و`/tmp` بسعة 64 MiB. يفحص المشرف الإلغاء والمهلة والصلاحية وينظف الحاوية. يحتفظ سجل التنظيف بمعرّفات وبصمات دون محتوى الأصل؛ لا يعيد تنفيذ المهمة بعد تعطل المشرف. الحاويات تشارك نواة محرك Docker، ولذلك لا ندعي حصانة كاملة أو إغلاق كل عمال المشروع.

لا يفك validator صورة المعاينة على المضيف: يفحص البنية والحجم وCRC والأبعاد والبصمة فقط. يبقى `document_vision.prepare_region` مسارًا مختلفًا يستعمل Pillow على المضيف للقص قبل فهم الصورة محليًا؛ هذا حد أمني باقٍ ولم يُختبر هنا كجزء معزول. كذلك بقيت مسارات وسائط أخرى خارج نطاق هذه الدفعة.

غلاف OCR يحتفظ بـTSV الخام، ويقبل الرأس الاختياري أو صفوف البيانات بلا رأس بعد التحقق منها. إحداثيات الكلمات وأرقام صفوف TSV إشارات للمصدر، ودرجات المحرك ليست احتمالات صحة معايرة. لا يُعكس النص العربي يدويًا ولا تُصحح الأرقام بصمت. تغيير صورة العامل أو وصفة المصدر يمنع استئناف صفحات بوصفة قديمة بـ409؛ الأصل المحفوظ يظل متاحًا.

## ميزانية الدفعة الحالية والتحقق

حُجزت 16 MiB في [سجل تنزيل مستقل مرتبط بالسجل السابق](../reports/document-isolation-downloads.json) قبل التنزيل. مجموع wheel هو **10,944,123 بايت**، ومجموع أجسام HTTP المحتسبة بما فيها تحقق PyPI الأولي **11,273,643 بايت**. صار الرصيد التجميعي **9,465,726,381 بايت** من سقف **10,737,418,240 بايت (10 GiB)**. هذا عدّ لأجسام الاستجابات، وليس قياسًا كاملًا لكل بايت على السلك. لم تُصفَّر المحاولات أو يُحتسب النسخ المحلي تنزيلًا جديدًا.

[التقرير الجامع](../reports/document-isolation-validation.json) يربط المصدر والتراخيص والاختبارات: 13 حالة استخراج فعلية وثلاث حالات فعلية للإلغاء وسحب الصلاحية والمهلة؛ 176 اختبارًا مركزًا بلا تخطٍّ في 33.79 ثانية. فحص imports منفصل عن OCR الفعلي. طابقت ثلاث عينات نظيفة، واحدة لكل لغة، النص بعد توحيد الفراغات فقط، مع فرق نهاية سطر في المطابقة الخام. لا يوجد تقدير عام لدقة العربية أو العبرية؛ PDF العربي المعقد ما زال يحول `RQ-742` إلى `50-742`.

نتائج UI الحالية وروابط المراجعة البصرية وحدودها في [دليل المستندات](DOCUMENTS.md). النسخة الخفيفة من المشروع لا تحفظ الأصول أو معاينات الصفحات؛ النسخة الكاملة من SQLite تحفظها بصورة منفصلة. ملف الإعداد والصور والمحرك المحلي موارد تشغيل خارج SQLite وليست جزءًا من snapshot المشروع.

## الإعداد التاريخي للمضيف، لا مسار بديل

يبقى `D:/RiwaqRuntime/documents-v1` مصدرًا محليًا مثبتًا لملفات OCR السابقة. حزم Windows المنسوخة آنذاك كانت pypdfium2 5.14.0 وopenpyxl 3.1.5 وet-xmlfile 2.0.0 وpython-pptx 1.0.2 وlxml 6.1.1 وXlsxWriter 3.2.9، مع تراخيصها. كانت حزم Python في python-packages، وNode في node_modules، واللغات في tessdata، وبصمات الملفات في runtime-manifest.json.

يحفظ [سجل الإعداد القديم](../reports/document-runtime.json) تنزيل **6,553,819 بايت** ونسخ **71,797,725 بايت** محليًا، وفحص 861 ملفًا. بلغ الإجمالي آنذاك 6,461,605,717 بايت تحت السقف السابق 8 GiB. هذه أرقام تاريخية، وليست الرصيد الحالي أو دليل عزل Docker. لا يُنصح بتشغيل document_worker.py أو OCR المباشر على ملفات غير موثوقة لتجاوز المسار الجديد.

نجح OCR القديم في [عينة عربية](../reports/document-ocr-arabic-smoke.json) لكنه قرأ «خصم» على أنها `aos` بثقة تقارب 75.95 وفقد بعض التشكيل. وكشف [سجل فحص TSV](../reports/document-ocr-debug.json) اختلاف الرأس بين WASM وCLI. تبقى هذه الإخفاقات محفوظة؛ لم يُستنتج نجاح لغوي من تشغيل WASM، ولم تدّعِ دفعة العزل الحالية إصلاح أخطاء OCR.
