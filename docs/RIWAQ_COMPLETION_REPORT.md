فشل الفحص الشامل الأول في8 اختبارات (1281 نجح):3 fixtures افترضت غياب إعداد Docker في مجلد المستخدم، و5 اختبارات frozen استهدفت حد العامل القديم. أُصلحت بيئة الاختبار وعقودها لتظل حالة غياب المحرك والرفض وعدم spawning مفحوصة، دون تعديل شروط المنتج لإنجاحها؛ [النتيجة السابقة](../reports/resume-final-pytest.xml). تشغيل sandbox المعلق ليس نجاحًا. ملفات التشغيل لم تتغير بعد تجميدها لهذا الفحص.

اختبار الواجهة الأول نجح في معاينة PDF ثم أخفق في مقارنة CRLF بنهاية السطر LF التي يرسلها textarea. صُحح harness ليقارن قيمة الإدخال الفعلية، مع شرط مستقل يحفظ النص الخام دون تغيير؛ [الإخفاق محفوظ](../reports/completion-documents-ui/2026-11-15T19-19-24.486Z/report.json). في الجولة الناجحة لم تُسجل أخطاء صفحة أو طلبات خارجية. فُحصت ثلاث لقطات بصريًا؛ [حدود المراجعة](../reports/resume-documents-visual-review.json).

العينة العربية النظيفة ذات26 محرفًا و5 كلمات حققت CER=0 وWER=0 بعد تطبيع whitespace فقط. عينة PDF عربية أخرى ما زالت تقرأ معرّف `RQ-742` خطأً؛ لا تعميم ولا إخفاء العيب خلف نجاح التشغيل. Qwen أعاد42kPa معS1 للصفحة المحددة وميّز النص الذي صححه المستخدم. زمن رفع/استخراج عينات الواجهة نحو2.24–5.22ثانية لكل ملف في هذه البيئة، وليس هدف p95 عامًا.

صورة المستندات المثبتة `sha256:7e784e81e843de07888ebb4fd3e2e5634deaa8b4196dddc2c92c2aa15ebae786`، وصورة المحلل العامv2 `sha256:aeaacbcbc264195fe9ac30e640aac6d77e53c8b85724a7187518038370e6bfd9`. الإعداد السابق محفوظ، وأصول المصدر السابقة في `reports/document-isolation-source-before` و`reports/resume-public-baseline`. لم يُعد تشغيل قاعدة المستخدم بهذه الجولة، ولم تُستبدل الأوزان أو بيئاتGPU.

أضيف11,273,643بايت من استجابات التنزيل الموثقة (wheels وmetadata)، فصار الإجمالي المسجل **9,465,726,381بايت** ضمن10GiB. مصدر الحزم PyPI الرسمي وبصماته، والتراخيص محفوظة في سياق الصورة؛ [السجل](../reports/document-isolation-downloads.json). لا تدريب أو خدمة مدفوعة. ليس الرقم قياسًا لكل بايت على السلك.

يبقى قرار التسليم **تطوير محلي جزئي قابل للمراجعة**. قص منطقة الفهم البصري على المضيف، وعزل عمال الوسائط وسياسة مشتقات البيانات والمخارج والمراجعة البشرية المستقلة عوائق حقيقية قبل المرحلة8. لا تُعد الصور أو OCR أو الفهرسة تدريبًا للأوزان.

## البيئة ونقطة الرجوع

العمل على Windows المستخدم x64، Python المشروع3.12.10، Node24.19.0، RTX5060 بذاكرة8151MiB وRAM31.84GiB. البنية القائمة FastAPI/SQLite وReact/TypeScript/Vite وTauri؛ لم تُستبدل. Docker Desktop4.99.0 وEngine29.9.3 فوق WSL2/Linux amd64 يعملان فعليًا. كان التثبيت لكل مستخدم خارج PATH؛ نتيجة الفحص القديم لم تكن دليلًا على غيابه. [جرد البيئة](../reports/completion-desktop-environment.json).

لا يوجد Git في المجلد. حُفظت [نسخة مصدر البداية](../reports/completion-baseline/manifest.json) من300 ملف ونسخ إضافية قبل التعديلات. قاعدة المستخدم لم تُستخدم في اختبارات الهجوم أو الواجهة؛ QA على8767 ببيانات اصطناعية مستقلة. قبل حفظ إعداد Docker الفعلي أُنشئت نسخة SQLite متسقة ومشفرة بـWindows DPAPI في `data/backups/completion-before-runtime-20261115.rwbackup`. [سجل التفعيل](../reports/completion-runtime-activation.json): لم يُشغّل خدمة المستخدم أو يرحّل قاعدته، وثُبت فقط `data/isolated-workers.json`. النسخة مرتبطة بحساب Windows الحالي ولا تشمل جميع ملفات الوسائط الخارجية.

للمراجعة: [بصمات المصدر النهائية ونطاق المقارنة](../reports/completion-final-manifest.json)، و[الفروق النصية](../reports/completion-source-changes.patch). نسخة البداية محدودة؛ الملفات غير الملتقطة فيها موسومة current_only_not_in_baseline وليست دليلًا على أنها أُنشئت بهذه الجولة. بيانات QA والمفاتيح والنماذج والاعتماديات مستبعدة.

الفحص الشامل للدفعة السابقة قبل هذا الاستئناف: **1224 ناجحًا،3 متجاوزة،86.71ثانية** في [التقرير النهائي](../reports/completion-final-source-pytest.xml). بناء TypeScript وVite نجح، مع تحذير حجم الحزمة الرئيسية؛ لا يساوي البناء اختبار كل وظيفة أو قارئ شاشة.

تعطل مساعد Computer Use مؤقتًا بسبب طلب متزامن، ثم شوهدت شاشة فشل بدء Windows الأصلية. كشف الفحص ملف `backend/reasoning_limits.json` ناقصًا من الحزمة، فأُضيف إلى مساري التغليف. وأثبت [قياس المنفذ](../reports/completion-native-port-probe.log) أن Windows أعاد ConnectionRefused بعد نحو ثانيتين؛ رُفعت مهلة الفحص من500ms إلى3s مع بقاء الرفض عند خطأ غير محسوم. بدأ التطبيق المصحح خادمه فعلًا، ونجح [قبول HTTP للحزمة](../reports/completion-native-http-after-fix.json) في7.313ثانية:401 قبل الاقتران، هوية واقتران محليان، Qwen حقيقي وبث مطابق للحفظ، وإلغاء بعدdelta وحالةcancelled، وحالات unavailable صريحة للعمال غير المعبأة.

أوقف المستخدم الجولة الأولى من Computer Use بزر Escape، فحُفظ ذلك الإخفاق وتوقفت إجراءاتها. بعد طلبه الاستئناف، اكتمل إغلاق النافذة الأصلية وتنظيف أبنائها وإعادة فتحها واستعادة الرسالة؛ الدليل الأحدث أعلاه. اقتران ومحادثة WebView والاختصار ما زالت غير مختبرة. لا بيانات QA أو رموزها داخل الحزمة، ولم تُغيّر حماية النظام أو تُقبل اتفاقية Docker نيابة عن المستخدم.

حُفظت الإخفاقات: أول pytest داخل sandbox توقف دون نتائج، وجولة التطوير الأولى كشفت401بدل503 ثم أُصلحت؛ اختبارات المتصفح الأولى كشفت JPEG، وأخرى فشلت بسبب selectors/انتظار في سكربت الاختبار دون خطأ منتج. لا تُنسب جولة غير مكتملة إلى نجاح.

### الصور: نجاح التنفيذ لا يساوي نجاح المحاولة الأولى

المحاولة الخام عند4خطوات شغّلت SD1.5 فعلًا لكن مرشح النموذج حجبها؛ لا صورة ناجحة منها. محاولة واحدة لاحقة بنفس الوصف والبذرة37، عند24خطوة المعتادة وبالمرشح نفسه، حُفظت وأعيد فتحها. الواجهة تعرض سبب الحجب. لا نسبة جودة عامة من تجربتين بإعدادين مختلفين. [المراجعة البصرية](../reports/completion-visual-review.json) تصف النتيجة كوعاء خزفي أزرق؛ التطابق الدقيق مع كلمةcup غير معتمد. النص العربي/العبري/اللاتيني في العينة مقروء بصريًا، لكن OCR للبكسلات ومراجعة بشرية مستقلة لم يُنفذا.
