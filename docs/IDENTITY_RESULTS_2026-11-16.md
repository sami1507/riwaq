# رواق — نتائج تطوير الهوية، 16 نوفمبر 2026

طُبق الاتجاه **B — العتبة المفتوحة** على الواجهة القائمة، مع الحفاظ على اسم رواق / Riwaq والعبارة «وضوح للفكرة. خطوة للعمل.». أُصلح تباين زر الخطر عند التحويم، واتساق الشعار والأيقونات، وازدحام خيارات المحرر، وظهور صف المشروع على الهاتف. [دليل الهوية](IDENTITY.md) هو المرجع الحالي للأصول والقواعد؛ هذا الملف يسجل ما نُفذ وكيف تحققنا منه وحدود القبول.

## النطاق وخط الأساس

- الفحص والبناء على حاسوب Windows الفعلي، Chrome `157.0.8103.52`، واعتماديات المشروع الموجودة. لا Git أو `AGENTS.md` في مجلد المشروع؛ لذلك يعتمد الرجوع على النسخ والبصمات، لا commit غير موجود.
- حُفظت 108 ملفات في [سجل خط الأساس](../reports/identity-20261116/baseline-manifest.json)، مع نسخ إضافية لسكربتات توليد الأيقونات والمعرض القديمة. لا يُستخدم هذا السجل لإعادة الكتابة فوق تعديلات لاحقة دون مقارنة.
- [التدقيق الأولي](../reports/identity-20261116/audit.json) حسب 52 زوجًا من أدوار الألوان من CSS، وراجع الخطوط والبصمات والأيقونات. هذا فحص ثابت محدود، لا تحليل كامل لكل cascade أو شفافية أو صورة خلفية. [مراجعة لقطات البداية](../reports/identity-20261116/baseline-review.json) منفصلة عنه.
- اختبار الواجهة استخدم خدمة الاختبار المحلية `127.0.0.1:8767` وبيانات اصطناعية في `reports/completion-live-data`. HTTP والتخزين فعليان؛ رسائل المحادثة البصرية مُعدة للاختبار وليست إجابات نموذج جديدة. لم يُختبر أي عميل أو مشروع حقيقي بهجوم أو حذف.

## القرار التصميمي وما تغير

أُعدت [دراسة محلية](brand/identity-study.html) بثلاثة اتجاهات، بالمحتوى والألوان ومقاس الشاشة نفسه: A كلمة بارزة ورمز قاف، B رمز مفتوح ومساحة قراءة تحريرية، C ثلاث ضربات وشبكة شرائط. اختير B بعد مراجعة الرسوم: يحافظ على الصلة بالرمز الموجود، بينما القاف وحدها تختزل الاسم، وشرائط C أقرب إلى الرموز العامة للصوت والتحليلات. هذا **حكم تصميمي**؛ لم تُجر دراسة تفضيل أو تعرف على العلامة، ولا نثبت تميزًا تجاريًا حصريًا بهذه المقارنة.

```powershell

$env:RIWAQ_DATA_DIR = Join-Path (Get-Location) 'reports/completion-live-data'
node frontend/scripts/identity-v2-qa.mjs --phase after
```

## الحدود والمخاطر المتبقية

- لا شهادة WCAG أو اختبار قارئ شاشة فعلي. فحوص التباين والتركيز واللوحة والمقاسات وعينات الاتجاه لا تثبت تغطية كل حالة أو لغة. الخطوط الـ11 المحلية وأربع رخص OFL جرى جردها؛ ملف العبرية الإضافي يشير إلى commit IBM Plex نفسه كما في manifest الأساسي.
- لا اختبار WebView أصلي أو تحديث cache أيقونة Windows أو تثبيت/توقيع حزمة. الأصول المصدرية محدثة، لكن EXE والحزمة المحمولة السابقة لم يُعاد بناؤهما في هذه الجولة.
- لا إثبات لتميز الاسم قانونيًا أو حصريته. [مسح التشابه الأولي](../reports/identity-20261116/asset-audit.md) محدود؛ لا يعد تصريح علامة تجارية أو ضمان تفرد.
- بقي حجم الحزمة الرئيسية تحذيرًا تقنيًا قابلًا للقياس لاحقًا. لم تُحذف ميزات أو تُغيّر أطر العمل لمعالجة الشكل، ولا يُستنتج إنجاز مهارات أو أمان المنتج من هذه الجولة.
- لم تُستخدم خدمات صور أو نماذج، ولم تحدث تنزيلات جديدة أو مصروفات API. التقرير يسجل **صفر استدعاءات نموذج وصفر طلبات خارجية في UI**؛ جرت طلبات HTTP محلية حقيقية إلى بيانات الاختبار، فلا يصح وصف الفحص بأنه بلا أي اتصال API.
