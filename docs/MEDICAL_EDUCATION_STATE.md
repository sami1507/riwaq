# المسار الطبي التعليمي — 17 نوفمبر 2026

أضيف مسار فعلي محدود يعتمد على موضوع يختاره المستخدم وحقول منظمة، مع مصادقة رواق وحراسة المشروع قبل الحساب وقبل التسليم. يقدم شرحًا بالعربية والإنجليزية، ومقارنة رقمية بمجال التقرير الذي أدخله المستخدم، وتحويل كتلة تعليميًا بمحرك الحساب الدقيق الموجود. لا يستخدم نموذجًا أو شبكة أو تخزين محتوى أو ذاكرة أو تدريبًا. لا يفسر كل سؤال حر ولا يقدم تشخيصًا أو جرعة شخصية.

## التنفيذ والربط

- `GET /api/projects/{project_id}/medical/capabilities`: النطاق والموضوعات ومراجعها وتواريخها وحدود الدعم.
- `POST /api/projects/{project_id}/medical/explain`: عقد `Explain` في `backend/medical_schema.py`؛ موضوع صريح، لغة، مستوى شرح، وحقول محددة بحسب الموضوع.
- `backend/medical_education.py`: النتائج والشرح من القيم المنظمة نفسها. تحويل `mcg/mg/g` يستعمل `backend.check_worker.Arithmetic`، ثم يعكس التحويل بفحص كسري مستقل. `mL` يحتاج تركيزًا ولا ينفذ هذا المسار تحويل الجرعات.
- `backend/medical_api.py`: يعيد فحص الجلسة وملكية المشروع بعد العمل، ويمنع التخزين المؤقت. حقول العميل `actor` و`tenant` و`verified` مرفوضة؛ `persist=true` و`allow_training=true` غير متاحين.
- ربط الموجّه في `backend/app.py` والواجهة من مسؤول تكامل المشروع؛ نتائج اختبارات API أدناه تخص الربط الفعلي. إثبات العرض التفاعلي مسؤول عن تقرير التكامل العام، وليس اختبارات هذا الملف وحدها.

لا توجد ترحيلات أو قاعدة بيانات طبية أو ذاكرة منافسة أو اعتماد جديد. الرجوع يتم بإزالة تسجيل `medical_api.router` وخيار الواجهة؛ لا توجد بيانات طبية محفوظة تحتاج ترحيلًا. تبقى قيود الهوية والحذف القائمة نافذة.

## ما تثبته الحالات وما لا تثبته

| الحالات | التنفيذ المثبت وحدوده |
|---|---|
| MED-001 | فرق العرض والتشخيص بمراجع NCI؛ المختصر والمفصل والتقني يحتفظون بالخلاصة ويضيفون عمقًا حقيقيًا. لا يفترض إصابة أو يطلب تاريخًا صحيًا. |
| MED-002، MED-003 | الحقول الناقصة والوحدة والغموض تمنع المقارنة. عند اكتمال تقرير منظم، تُقارن القيمة بمرجعه فقط ويُحفظ تاريخ العينة. المدخل موصوف بأنه مقدم من المستخدم وغير موثق مستقلًا؛ المقارنة ليست تشخيصًا. |
| MED-004 | عند تحديد علامتي ألم صدري شديد مستمر وضيق تنفس، يتقدم توجيه المساعدة الطارئة على كل موضوع وشرح. لا يذكر رقم بلد مجهول. ليس مصنف أعراض حرًا أو دليلًا على استبعاد خطر آخر. |
| MED-005 | لا يختار جرعة شخصية من اسم تجاري مبهم؛ يحدد المعلومات اللازمة ويشير إلى الطبيب أو الصيدلي. |
| MED-006 | تحويل تعليمي دقيق: `500 mcg = 0.5 mg`، مع عكس التحويل للتحقق. لا يثبت ملاءمة الجرعة. |
| MED-007 | حارس عدم الدعم يعمل؛ **الآلة السريرية نفسها غير منفذة**. يلزم اختيار صيغة موثقة وفئة سكانية ومدخلات ومراجعة مؤهلة قبل أي ادعاء سريري. |
| MED-008 | **جزئي**: يقارن بلدًا وسكانًا وتاريخًا أدخلها المستخدم ويصرح بأنها غير موثقة. لم يُجلب محتوى توصيتين أو يُحسم تعارضهما؛ لا تساوي هذه النتيجة قبول الحالة كاملة. |
| MED-009 | يستقبل تصريح الغموض ويرفض تخمين الرقم/الوحدة. الصور الخام غير مدعومة؛ ليس هذا استخراج OCR أو تحليل أشعة. |
| MED-010 | يعلن أن التحذير الحديث لم يُتحقق منه. لا يُستخدم مرجع ثابت لإظهار تحقق حي. التحقق الدوائي الحديث نفسه غير متاح هنا. |
| MED-011 | **جزئي**: شرح التصميم الرصدي وأسئلة المربكات والسببية؛ لم تُقرأ دراسة المستخدم أو تُراجع نتائجها. |
| MED-012 | **جزئي**: تصحيح الحقول يعيد الحساب دون حفظ المحتوى، واختبار SQLite يثبت غياب النسخة والمشتقات في المحادثة والذاكرة وسجلات التعلّم. لا يوجد اعتماد آلي لحقائق طبية أو مثال تدريب؛ حلقة فيدباك طبية موثقة لم تُنفذ في هذا المسار. |

تتضمن الاختبارات حالات إضافية للصفر والأرقام العربية والقيمة الكبيرة والحقول الفارغة، ورفض النص التنفيذي والمدخل الملتبس، والوصول إلى مشروع آخر أو جلسة منتهية وسحب الصلاحية قبل التسليم. هذه اختبارات تطوير مكشوفة؛ لا تُوصف بأنها اختبار محجوز مستقل أو قياس لتعميم نموذج.

## المصادر والحداثة

السجل `config/medical_sources.json` يحفظ الرابط والعنوان والناشر وتاريخ الوصول وموقع الدعم والسكان والبلد وتاريخ التحديث **عندما ظهر فعلًا**؛ التاريخ غير المعروف يبقى `null`. كل جواب يربط الحقول المدعومة بسجلات مصدر واضحة ويصف الحداثة بأنها مراجعة تطوير، لا وصولًا حيًا وقت الإجابة. القيم التي أدخلها المستخدم لا تتحول إلى حقائق موثقة لمجرد وجود إحالة.

- تعريفات [العرض](https://www.cancer.gov/publications/dictionaries/cancer-terms/def/symptom) و[التشخيص](https://www.cancer.gov/publications/dictionaries/cancer-terms/def/diagnosis) و[العلامة](https://www.cancer.gov/publications/dictionaries/cancer-terms/def/sign) من NCI تدعم درس المصطلحات فقط.
- [MedlinePlus: نتائج المختبر](https://medlineplus.gov/lab-tests/how-to-understand-your-lab-results/) يدعم حدود استنتاج التشخيص وضرورة مرجع التقرير وسياقه؛ لا يثبت رقمًا خاصًا بالمستخدم.
- [NHS: ألم الصدر](https://www.nhs.uk/symptoms/chest-pain/) يدعم أولوية المساعدة عند التركيبة الصريحة. الصفحة المقروءة تحمل مراجعة 2023-08-08 وموعد مراجعة 2026-08-08؛ تسجيل الوصول في 2026-11-17 لا يعني تحديث المحتوى. لا تُنقل أرقام طوارئ بريطانيا إلى بلد مجهول.
- [NCI: الدراسة الرصدية](https://www.cancer.gov/publications/dictionaries/cancer-terms/def/observational-study) يدعم تعريف التصميم، وليس استنتاجًا من بحث لم يُقرأ.
- [AHRQ: Teach-Back](https://www.ahrq.gov/health-literacy/improve/precautions/tool5.html) يدعم سؤال فهم اختياري بوصفه اختبارًا لوضوح الشرح، بعد إعطاء الجواب كاملًا. [WHO](https://www.who.int/news/item/18-01-2024-who-releases-ai-ethics-and-governance-guidance-for-large-multi-modal-models) مرجع حوكمة وحدود استخدام، وليس اعتمادًا لرواق.
- صفحة NICE NG197 ونسخة PDF الرسمية أعادتا 403 في الفحص؛ السجل يوسمهما غير متاحتين ولا ينسب إليهما ادعاءً.

سجل المصادر ليس سجل زحف مأذونًا ولا يتجاوز سياسة البحث القائمة. إضافة مرجع أو تحديثه تحتاج قراءة المصدر الرسمي وموضع دعمه وتوثيق تاريخ التغيير وتشغيل الاختبارات المتأثرة. العلاج والتحذيرات المتغيرة تحتاج تحققًا حيًا ضمن مسار البحث المأذون وملاءمة البلد والمنتج والسكان؛ لا يكفي تغيير `accessed_at`. لا يتلقى المسار الطبي رابطًا يرسله العميل لجلبه، لذلك لا يفتح مسار SSRF جديدًا.

## أدلة التشغيل

خط الأساس الفعلي قبل تسجيل الموجّه في `reports/medical-20261117/baseline.json`: بعد تسجيل دخول حقيقي في تخزين اختباري معزول، أعاد GET القدرات 404 وPOST الشرح 405 ولم يوجد مسار طبي مسجل. لم يكن ذلك تقييمًا لدقة النموذج الطبية. محاولة TestClient الأولى داخل عزل التنفيذ تعثرت وأوقفت؛ ثم أُعيدت محليًا بصلاحية التنفيذ المناسبة. لم تُعد المحاولة المتوقفة نجاحًا.

أوامر إعادة التحقق من جذر المشروع:

```powershell
.venv/Scripts/python.exe -m pytest tests/test_medical_education.py -q --junitxml=reports/medical-20261117/pytest-medical.xml
.venv/Scripts/python.exe tests/record_medical_evidence.py
```

النتيجة المسجلة: 43 اختبارًا ناجحًا، دون تخطٍّ؛ JUnit يحفظ تفاصيل التشغيل. `verification.json` يحفظ الأوامر والبيئة وبصمات الملفات والنتائج وحدود كل حالة. `samples.json` يحتوي مخرجات عربية وإنجليزية فعلية بمدخلات اصطناعية فقط. لا يُحفظ رمز الاقتران أو الجلسة أو قاعدة البيانات في هذه الأدلة. لم تُستخدم مكالمات نموذج في المسار؛ لذلك لا توجد مقارنة صحة نموذج أو تكلفة نموذج، ولا نسبة تحسن سريري صالحة للاستنتاج.

## العوائق وخطوة الاستئناف

**المراجعة الطبية المؤهلة غير منفذة، والاستخدام السريري غير معتمد.** يلزم مختص مؤهل يراجع النطاق والمصادر والسيناريوهات والإجابات المتوقعة وحدود الإحالة، ثم تقييم مستقل قبل أي استخدام سريري. لا ينوب نجاح الاختبارات البرمجية عن ذلك. هذه الخطوة لا تتطلب تغييرًا صوريًا في علم `qualified_review_completed`؛ تحتاج سجل مراجعة حقيقيًا ونطاقًا معلومًا.

يبقى دمج فحص المصادر الطبية الحي، وحسم توصيتين فعليتين، ومراجعة دراسة بعينها، وصيغة حاسبة سريرية، والتقييم الطبي المحجوز عملًا غير منجز. يستأنف داخل البحث والأدوات الحالية مع حقوق وصول ومصادر ومراجعة محددة؛ لا يُغلق بتوسيع درس ثابت أو بتدريب غير مخوّل. أما المسار المنفذ فهو استخدام تعليمي صريح وحقول منظمة وضوابط يمكن فحصها.
