# مصفوفة عزل العمال — GAP-003

آخر تحديث: 18 نوفمبر 2026. تصف هذه الوثيقة كل موضع تبدأ فيه الخدمة عملية أخرى، وما الحد الفعلي حول كل منها. «عملية محدودة» على الجهاز **ليست** عزل نظام تشغيل، وتُذكر هنا بهذا الوصف.

القائمة مثبتة آليًا: `tests/test_core_worker_inventory.py` يفشل إذا ظهر موضع تشغيل جديد أو استدعاء عبر الصدفة قبل مراجعته وإضافته هنا.

## القاعدة المعمارية

البايتات غير الموثوقة (ملف مرفوع، صورة، صوت مضغوط، شيفرة للفحص، صفحة ويب) تُفتح داخل الحاوية فقط. العمال على الجهاز يستقبلون ناتجًا مُطبَّعًا ومتحققًا منه (PCM، صورة مطبَّعة، نص، JSON بحقول محددة)، لا الملف الأصلي.

## ما لم يُنجز

- لا حد من نظام التشغيل على الملفات أو الشبكة للعمال على الجهاز (لا AppContainer ولا رمز مقيد ولا قاعدة جدار ناري). إضافته تغيّر طريقة تشغيل نماذج الصور والصوت وتحتاج تجربة على الجهاز لكل عامل.
- عامل تحويل الكلام والآلة الحاسبة ومحلل الشيفرة بلا Job Object.
- الحاوية تشارك نواة محرك Docker؛ ليست آلة افتراضية مستقلة لكل مهمة.
- تثبيت بصمة صور العمال داخل إعداد الحزمة المعبأة لم يُنفذ.
- المراجعة الأمنية البشرية المستقلة لم تُجرَ.
