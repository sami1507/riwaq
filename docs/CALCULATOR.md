# الحاسبة الصريحة في رواق — calculator-v1

التاريخ: 14 نوفمبر 2026. هذه نتيجة المهمة N1 في [الخطة](RIWAQ_ROADMAP.md)، وليست تدريبًا أو تغييرًا لأوزان النموذج. أعيد استخدام العامل الحسابي الموجود، مع مسار مستقل في المحادثة.

## الاستخدام

اختر «حاسبة» بجانب «محادثة»، ثم أدخل تعبيرًا مثل (19.95 * 3) * 1.17 - 10 واضغط «احسب». تُعرض القيمة الدقيقة 60.0245، ويحفظها رواق مع التعبير وسجل الأداة. التعبير 1/3 يُعرض ككسر دقيق؛ لا يُستبدل بعشري مقرب غير معلن.

يدعم الإدخال الأعداد العشرية والأقواس وعمليات الجمع والطرح والضرب والقسمة، والأرقام العربية الهندية مثل ١٢٫٥ × ٢. لا يدعم هذا الوضع الأسس أو النسب المئوية أو المتغيرات أو الوحدات أو الأسئلة المكتوبة بلغة طبيعية. لا يستخرج معادلة من مسألة تلقائيًا؛ صياغة التعبير مسؤولية المستخدم. للمناقشة والشرح اختر «محادثة»؛ يظل شرح النموذج تجريبيًا.

للوضعين مسودتان مستقلتان داخل الجلسة. فشل الحساب أو تبديل الوضع لا يمسح التعبير. الحساب الناجح يحفظ الرسائل والنتيجة ولغة النتيجة في SQLite. التعديل ينشئ فرعًا، وإعادة المحاولة تعيد الحساب بلغة الرسالة الأصلية؛ لا تستعمل وضع المحرر الحالي بدلًا منها. الملفات والحقائق والتعليمات وذاكرة المشروع لا تدخل عملية الحساب.

## العقد والتنفيذ

نفس POST /api/conversations/{id}/generate، مع payload محدود:

    {"content":"0.1+0.2","answer_mode":"calculator","result_language":"ar"}

الوضع العادي هو assistant؛ لا تُحوّل الأرقام إلى طلب حاسبة تلقائيًا. اختيارات المصادر أو العمق أو الفرضيات أو مراجعة النموذج أو JSON أو الحقائق المفعلة تُرفض مع الحاسبة. اختيار مزود سحابي أو غياب النموذج لا يستدعيه ولا يمنع الحساب المحلي.

ينفذ الخادم reasoning.checker مرة واحدة أثناء التجهيز، قبل كتابة رسائل أو إنشاء فرع. تُرفض التعابير غير الصالحة والقسمة على صفر برمز 422 بلا حفظ نتيجة؛ المهلة أثناء التجهيز 504 والمحرك المعلن غير المتاح 503. إذا تجاوز الموعد بعد بدء قناة البث، تُحفظ حالة interrupted ويُرسل خطأ دون نتيجة نجاح. الإلغاء قبل الحفظ يعيد 499 ويلغي مهمة العامل. لا نموذج بديل ولا نتيجة مصطنعة.

النجاح يستعمل قناة NDJSON الحالية: start ثم delta ثم done. هذه نتيجة محددة تُرسل كدفعة نصية، وليست بث رموز من نموذج. model المحفوظ هو riwaq-calculator-v1، والسياسة calculator-v1، واستدعاءات النموذج صفر والأداة واحدة. السجل يحتوي التعبير المنظّم والكسر والعشري وإعدادات العامل؛ لا سجل تفكير داخلي.

حُفظ answer_mode و result_language في retrieval_options لكل من رسالتي المستخدم والمساعد، وفي request_options لسجل الفحص. احتُفظ باسم حقل النقل القديم للتوافق، رغم اتساع معناه. الرسائل القديمة تظل assistant دون تخمين من المحتوى. النسخ المستعادة تحفظ سجلًا تاريخيًا معلّمًا؛ الاستعادة لا تعيد الحساب ولا تمنح بياناتها صلاحية تنفيذ.

حدود العامل: 512 محرفًا، 128 رمزًا نحويًا، عمق أقواس 16، 64 محرفًا للعدد الواحد، وحد 2048 بت للبسط والمقام. العامل ثابت، بحد ذاكرة 256 MiB ومراقب CPU ثانيتين ومهلة أصلية خمس ثوانٍ. ميزانية مسار الحاسبة عشر ثوانٍ، وتُفحص قبل اعتماد معاملة الحفظ وقبل إخراج النتيجة. هذه ليست بيئة لتنفيذ شيفرة حرة.

## النتائج المقاسة

- النسخة السابقة المدققة: 341 اختبارًا ناجحًا وواحد متجاوز. تحققت مطابقة 224 بصمة مصدر قبل التعديل وحُفظت نقطة رجوع؛ لم يُعاد تسمية تلك النتائج تشغيلًا جديدًا.
- بعد التنفيذ: 372 اختبارًا ناجحًا وواحد متجاوز في 27.69 ثانية، مع تحذير pypdf السابق. أضيفت 31 حالة للحاسبة، منها الحساب الحقيقي والحفظ والتفرع والنسخ والصلاحيات والمهلة.
- 127 اختبارًا سابقًا للمحادثة والاستدلال والعقود والنسخ والحقائق اجتازت الفحص المرحلي؛ هي جزء من المجموعة النهائية وليست 127 نتيجة إضافية مستقلة.
- [اختبار التشغيل المحلي وإعادة التشغيل](../reports/calculator-offline.json): أربعة تعابير صحيحة باستخدام HTTP والعامل الحقيقي وSQLite؛ استعادة مطابقة بعد إعادة تشغيل الخادم. اختيار Anthropic ونموذج غير موجود في قاعدة اختبار مؤقتة لم يسبب أي اتصال. حارس العملية منع اختبار اتصال بـ Ollama وآخر خارجي، ثم رصد صفر محاولة اتصال خلال الحالات الأربع.
- زمن تلك الحالات نحو 0.109–0.110 ثانية على الجهاز الحالي؛ عينة صغيرة، وليست ضمان أداء. الحارس على واجهات Python/asyncio، وليس فصلًا لشبكة النظام؛ العامل الثابت له حدوده المنفصلة.
- محاكاة الفشل والإلغاء في tests/test_calculator_mode.py معلّمة، ولا تُقدّم كدليل مستقل على قتل عملية OS. اختبار مهلة العامل الحقيقي الموجود في test_reasoning.py اجتاز الفحص. اختبارات تجاوز موعد التجهيز والبث الجديدة تستعمل العامل الحقيقي وتعدّل موعد المهمة وحده.
- المقارنة مع audit-live محددة: التعبير نفسه أعطت أداته 60.0245 بينما انتهى شرح النموذج القديم إلى 59.9945. الوضع الجديد يحفظ ويعرض 60.0245 دون شرح مولّد. هذا فصل لمسار الحساب، وليس مقارنة ذكاء أو إثبات تحسن النموذج؛ الإجابة القديمة باقية في سجلها.

## التحقق من الواجهة والنسخة النهائية

[تقرير المتصفح](../reports/calculator-ui/report.json) يثبت 11 حالة، منها النتيجة الدقيقة والكسور والأرقام العربية والتحرير وإعادة المحاولة وحفظ مسودتي الوضعين ورفض المدخلات دون إضافة رسائل. فُحصت خمسة عروض في الوضعين: العربية عند 360 و390 و768، والإنجليزية عند 1280 و1440؛ ليست كل توليفات اللغة والعرض. لا قص في العناصر الأساسية أو خطأ صفحة أو طلب متصفح خارجي.

حالة غياب النموذج في فحص الواجهة وحدها استُبدلت ببيانات حالة مضبوطة؛ طلبات الحساب ونتائجها والتخزين فعلية. الاختبار المنفصل بحارس الاتصالات يثبت عدم حاجة API إلى مزود؛ لا تُخلط التجربتان ولا يُدّعى إيقاف Ollama الرئيسي. [لقطة هاتف عربية](../reports/calculator-ui/390-ar-light.png) و[لقطة حاسوب داكنة](../reports/calculator-ui/1440-en-dark.png) روجعتا هندسيًا؛ لم يُجر اختبار قارئ شاشة أو جهاز لمس مادي.

فشل فحص المتصفح أولًا بسبب locator لحقل JSON بعد إعادة تركيبه، وصُحح إلى الاسم الذي تعرضه واجهة الوصول. [دليل فشل أداة الفحص](../reports/calculator-ui/harness-label-failure.json) محفوظ؛ ليس عطلًا في الحساب.

البناء النهائي ناجح: JavaScript 604.56 KB وCSS 84.40 KB؛ تحذير الحزمة فوق 500 KB باقٍ. [إعادة التشغيل النهائية](../reports/calculator-final-restart.json) استرجعت حساب المتصفح ثم حسبت 1/3 وحفظته واستعادته. [ملخص التحقق](../reports/calculator-validation.json) و[بصمات 228 ملفًا](../reports/calculator-code-manifest.json) يحددان النسخة الحالية دون commit مختلق.

يمكن تشغيل الحاسبة من المصدر دون بدء Ollama بواسطة .venv/Scripts/python.exe -m backend.launcher بعد بناء الواجهة. سكربت start.ps1 المعتاد يحاول أيضًا تشغيل Ollama لدعم المحادثة. العامل الحسابي غير مجهز داخل الملف التنفيذي المجمد؛ لا حزمة سطح مكتب جاهزة مُدّعاة.

## الملفات والرجوع

backend/app.py يوجّه الطلب ويحفظه ويحد المهلة؛ backend/reasoning.py يعرّف خيارات الرسائل وإيصال الحاسبة وإخراجها؛ الواجهة في App و api و VerificationLedger و reasoning.css. لا اعتماديات جديدة أو تنزيلات أو خدمات مدفوعة. استهلاك الكهرباء غير مقاس.

نقطة الرجوع: D:/RiwaqBuild/backups/calculator-v1-2026-11-14/source وملف riwaq.sqlite3 في المجلد الأب. حُفظت نسخة ما بعد التغيير باسم after.sqlite3 وفُحص اتساقها. لا تستبدل قاعدة المستخدم للرجوع عن الواجهة. إن أعدت كودًا أقدم لا يفهم metadata الجديدة، استخدم نسخة بيانات منفصلة متوافقة ولا تفترض أن البرنامج القديم يحافظ عليها.

أوامر إعادة التحقق من المصدر:

    npm --prefix frontend run build

    node frontend/scripts/calculator-ui.mjs
