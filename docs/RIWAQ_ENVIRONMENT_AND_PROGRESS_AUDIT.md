## المطلوب حسب النوع

1. **تنزيل الآن:** لا شيء لتشغيل الويب/المحادثة المحلية. مرشحا تحديث torch و urllib3 أعلاه إصلاح لاحق محدد،بعد تثبيت توافق وحجم وميزانية؛لا تنزلهما عشوائيًا في `.venv` الأساسية.
2. **إعداد:** استخدم `.venv/Scripts/python.exe`؛الخدمة تعمل الآن فلا تشغّل نسخة ثانية على 8765. للاستخدام،افتح `http://127.0.0.1:8765` وشغّل صراحة من مجلد المشروع `.\scripts\pair-browser.ps1 -Copy` ثم الصق الرمز في الواجهة. لم أُنفذ النسخ أو إصدار رمز لك أثناء الفحص. إذا توقفت الخدمة لاحقًا،سكربت التشغيل المعروف هو `.\scripts\start.ps1`. تهيئة Git للتتبع خطوة تنظيمية لاحقة،ولم تتم تلقائيًا.
3. **إصلاح كود/أمان:** عزل العمال،تعميم سياسة البيانات والأذونات،وإعادة تحقق الحزمة/الاستعادة؛هذه أولوية التقدم. الزيادة في عدد البرامج المثبتة لا تحلها وحدها.
4. **مفتاح خدمة:** لا مفتاح مطلوب للمحادثة المحلية. محرك بحث عام أوفيديو سحابي يحتاج اختيار مزود وتكلفة وتفويض ومفتاح خادمي لاحقًا؛المزود الحالي العام غير جاهز. لا ترسل مفتاحًا هنا. وحتى وجود مفتاح LLM لا يرفع حجب Guard.
5. **تحقق المستخدم:** الميكروفون والسماع الحقيقيان مؤجلان بطلب سابق؛النطق العربي غير متوفر. قبول تطبيق Windows الأصلي لم يُنجز. WSL يحتاج استعلامًا من جلسة مناسبة فقط إذا اختير لذلك مسار فعلي؛لا نعطل حماية Windows لإكماله.
