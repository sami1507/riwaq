## ما أثبتته المسارات الحية

العينة الجديدة صغيرة ومكشوفة، وليست benchmark أو اختبارًا محجوبًا:

- نقص بيانات السرعة: صرّح بعدم كفاية المسافة والزمن.
- «كل عدد أولي فردي؟»: قدّم 2 كحالة مضادة؛ النتيجة صحيحة والشرح أطول مما يلزم.
- الحساب الدقيق: الأداة صحيحة والنموذج أخطأ كما في A-05.
- سنة 2026: معرّفات وشواهد صالحة، لكن امتناع غير ضروري كما في A-06.
- تصحيح السنة: لا شواهد قبل الإصلاح؛ بعده 17kPa مع[S1] وتنبيه أن البيانات اصطناعية.
- إعادة المحاولة أنشأت فرعًا وحفظت خيارات المصادر، لكنها كررت خطأ الجودة؛ نجاح المسار لا يثبت صحة الجواب.
- الإلغاء حفظ جزءًا وحالة cancelled. حذف ملفي التدقيق أزال المقاطع، والسؤال اللاحق أظهر نقص الأدلة بلا اختلاق مراجع.
- UI فعلي أرسل 6 × 7 وأعاد 42 وحفظها واستعادها.

أول سؤال استغرق 75.81 ثانية؛ لا تُنسب المدة للتحميل البارد دون metrics كافية. بقية العينة نحو 0.28–3.66 ثانية، والإلغاء نحو 0.61 ثانية. اختلاف الطلبات وصغر العينة يمنعان تعميم سرعة.

واجه سكربت التدقيق 405 لأنه استخدم DELETE /files/id بدل المسار المقيّد بالمشروع؛ صُحح ثم ثبت الحذف. هذا خطأ أداة الفحص وليس ثغرة بالتطبيق. اختبار UI متزامن مع التوليد تلقى 409 المتوقع، ثم أُعيد بعد انتهاء العمل ونجح. الدليلان محفوظان.

### الصور والنص

SD1.5 نُزّل قبل التدقيق من مرآة غير تابعة للناشر الأصلي، revision 451f4fe…، مع CreativeML OpenRAIL-M ومرشح المحتوى وبصمات. لا API خارجي أو رفع صور خاصة.

أول CLI: 512 × 512 في 28.437 ثانية، أعلى CUDA reserved 3,697,278,976 بايت؛ الكوب مقصوص. اختبار API لاحق: نحو 19.125 ثانية داخل العامل و 24.422 ثانية مع الإشراف، وأعلى RSS للشجرة 2,442,739,712 بايت. [الصورة](../reports/audit-visual/generate.png) أظهرت كوبًا كاملًا لكن مقبضه يسارًا رغم طلب اليمين، وعنصرًا خلفيًا إضافيًا. **نجاح التشغيل والحفظ لا يساوي اتباع كل قيود التصميم.** PNDM نفذ 25 callback لـ 24 خطوة مطلوبة؛ العداد صار حسب جدول التنفيذ الفعلي.

[النص العربي المصدّر](../reports/audit-visual/render.png) حافظ على السلاسل وبصماتها وحدود الحبر. مراجعة هندسية بواسطة AI لصورة واحدة أظهرت حروفًا متصلة ومقروءة؛ ليست مراجعة بشرية مستقلة. لا OCR أو CER/WER بصري أو اعتماد شامل للغات. حفظ CRLF/NFD و cmap لا يثبت دقة كل glyph. لا وعد «من أول مرة» أو متوسط نجاح مختلق.

الإلغاء أوقف عاملًا فعليًا ولم ينشر asset. اختبارات الإشراف تتحقق من العمليات الثابتة؛ 12 GiB RSS ومهلة 90 ثانية للرسم/300 للتوليد ليست عزلًا عامًا. الشبكة محمية بـ Python socket/local_files_only أو Chromium request routing، وليست جدار نار OS.

لا واجهة تصميم كاملة، ولا اختبار حي JPEG/WebP والشفافية في كل المسارات أو img2img؛ ولا طباعة/PDF/SVG أو 3D حقيقي أو QR أو image LoRA. لا تُعرض هذه القدرات كجاهزة.

### الحسابات والصلاحيات

test_sync ينشئ حسابين بكلمات مرور scrypt وبنفس project_id؛ كل حساب يرى بياناته فقط. يشمل سحب/انتهاء الجلسة وتعارض المراجعات. بيانات الاختبار (fixtures) للظرف المشفّر هنا opaque bytes؛ الاختبار يثبت الملكية والتخزين، لا HTTPS أو تشفير متصفح جديد. تقرير التشفير السابق منفصل.

فُحصت حدود الملفات والمشاريع والحقائق والمصادر ومنع السياق المسحوب. لا واجهة shell تمنحها تعليمات مصدر للنموذج. منع SSRF والروابط وسحب المصادر مطبق بالكود والاختبارات، لا بالبرومبت فقط. لا ادعاء لعزل خدمة الجهاز عن عملية تعمل بحساب OS نفسه.
