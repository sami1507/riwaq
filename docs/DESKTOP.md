رِواق يشارك واجهة React والخدمة المحلية بين الويب وغلاف Tauri. خدمة FastAPI المضمّنة عبر PyInstaller تعمل على `127.0.0.1:8765` وتقدّم الواجهة والـAPI من المصدر نفسه. Ollama وأوزان النماذج واعتماديات الوسائط الخارجية منفصلة عن الحزمة.

[بيان النسخة والبصمات](../reports/skills-batch-02-20261116/package-validation.json) هو مرجع بايتات الحزمة الحالي؛ [سجل البناء](../reports/skills-batch-02-20261116/package-build.log) يحفظ التحذيرات، ومنها hidden import اختياري لـtzdata لم يمنع المسارات المختبرة.

[الدليل](../reports/skills-batch-02-20261116/packaged-service-acceptance.json). لا نموذج أو فوترة سحابية في هذا الفحص. اختبارات Docker والصوت وOCR من بيئة المصدر لا تُنسب تلقائيًا إلى خدمةPyInstaller.

شُغّل `riwaq.exe` نفسه، وشوهدت **نافذة WebView2 الأصلية وصفحة الاقتران العربية** بالهوية الحالية وحقل الرمز فارغًا، ثم أُغلقت بزر النافذة. [اللقطة الآمنة](../reports/skills-batch-02-20261116/native-pairing.jpg) و[شجرة الوصول](../reports/skills-batch-02-20261116/native-pairing-accessibility.txt) توثقان ما شوهد. استُخدم `RIWAQ_DATA_DIR` لقاعدة اختبار منفصلة، وضُبط `WEBVIEW2_USER_DATA_FOLDER` ضمن عملية الاختبار لمسار خاص؛ لم تُقرأ ملفاتcookies أو حسابات المستخدم. تفاصيل المسارات والعمليات في [سجل التشغيل](../reports/skills-batch-02-20261116/native-launch.json).

**اختبار ما بعد الاقتران داخل النافذة متبقٍ باختيار المستخدم الصريح.** لم يُدخل المساعد رمزًا أو يحقن جلسة فيها. لا يُدّعى أن المهارات الجديدة استُخدمت من WebView2 لمجرد نجاحها في Chrome أوHTTP. بدء النافذة لا يثبت الرحلة الكاملة أو قارئ الشاشة أو تحديثًا موقّعًا أو اختبارOffice الأصلي.

بعد الإغلاق انتهت العمليات العشر التابعة التي رُصدت، وأثبت جدول TCP في Windows غياب مستمع8765. فحصsocket منفصل أعاد10035غير حاسمة، فحُفظت ولم تُفسر نجاحًا. [الملخص الأصلي](../reports/skills-batch-02-20261116/native-smoke.json)، [تنظيف العمليات](../reports/skills-batch-02-20261116/native-cleanup.json)، و[فحص المنفذ](../reports/skills-batch-02-20261116/native-port-listener-check.json). أُنشئ مسار WebView التجريبي و`EBWebView/Default` في وقت التشغيل، لكن مقارنة وسائط العملية بالمسار لم تُحسم؛ لا يقدّم هذا التقرير تدقيقًا كاملًا لعزل ملفات المتصفح.

العمال غير المعبّأة تعرض عدم التوفر صراحةً؛ أثبت فحص الحزمة `packaged_worker_unavailable` لاستخراج المستندات بدل تشغيله خفية على المضيف. Ollama والأوزان وأصوات النظام وصورDocker تبقى اعتماديات خارجية، ولا تسحبها الحزمة تلقائيًا. نسخة التطوير من المصدر هي المرجع للقدرات التي اختُبرت بعمالها المحلية. لتجربة مصدر رواق اتبع README؛ لا تحذف بياناتك أو تنقلها إلى قاعدة الاختبار.

لاستئناف قبول النافذة، شغّل المرشح بقاعدة اختبار معزولة، وأتم الاقتران محليًا بنفسك باستخدام `scripts/pair-browser.ps1 -Copy -DataDirectory <مسار قاعدة الاختبار>`، ثم اختبر حفظ ملف وتلخيصه وإعادة فتحه داخل النافذة. لا ترسل الرمز في محادثة. الرجوع إلى المرشح السابق ممكن لأنه لم يُستبدل؛ قارن إصدار المخزن واحفظ قاعدة البيانات قبل تبديل إصدار التطبيق، ولا تُسقط دفتر الحجوزات أو نقاط الاستئناف لمعالجة عطل.

## سجل تاريخي — 15 نوفمبر 2026

**قبول محلي جزئي للحزمة الجديدة** في `D:/RiwaqBuild/resume-document-isolation-20261115/portable/Riwaq`. أُعيد بناء الواجهة وPyInstaller وTauri بالاعتماديات الموجودة وCargo offline/locked، في مجلد مستقل عن الحزمة السابقة. لم تُغيّر حماية Windows أو أوزان النماذج.

أُغلقت نافذة الحزمة الجديدة من شريطها، وانتهت العمليات المسجلة طبيعيًا، ورفض المنفذ الاتصال. أُعيدت الحزمة نفسها بقاعدة QA الاصطناعية نفسها؛ استُعيد معرّف الرسالة ونصها وحالة complete، وبقي الرد الملغى cancelled، دون توليد جديد. شوهدت صفحة الاقتران بعد إعادة الفتح، ثم أُغلقت نسخة الاختبار وأُثبت انتهاء أبنائها. لم تُستخدم قاعدة المستخدم. مرجع القبول `reports/resume-native-http-20261115.json` و`resume-native-stopped.json` و`resume-native-restored.json` و`resume-native-final-stopped.json`؛ التلخيص المحدود داخل `VALIDATION.json` في الحزمة النهائية.

المحادثة والاقتران داخل WebView والاختصار وقارئ الشاشة والتثبيت والتوقيع الرقمي **لم تُختبر**. فحص HTTP ودورة الحياة لا يعوّضانها؛ هذا ليس قبولًا كاملًا أو مراجعة أمنية بشرية مستقلة. الحزمة السابقة وأدلتها بقيت محفوظة ولم تُنسب نتائجها للحزمة الجديدة. أوقف المستخدم محاولات CUA تاريخية بـEscape؛ الجولة الحالية استُؤنفت بطلبه واكتملت دون تعطيل زر الإيقاف.

فحص جاهزية أول لإعادة الفتح أغفل `X-Riwaq-Client: local`، فتلقى403 رغم عمل الخدمة. جرى تصحيح أداة الفحص فقط، ثم تحقق200 مع الرأس الصحيح واستعادة الرسالة؛ لم يُخفف ضابط الخادم.

**سجل تاريخي:** في 12 نوفمبر منعت Windows Application Control برامج بناء Rust ثم ملف خدمة PyInstaller بالخطأ OS4551. لم تُغيّر سياسة الجهاز ولم يُستخدم إعادة تسمية للتحايل عليها. في التجربة الحالية اشتغل الغلاف والخدمة الناتجان دون تعديل سياسة Windows؛ لا يعني ذلك اختبار كل عامل أو اعتماد حزم أقدم.

## العيوب التي كشفها قبول الحزمة

- الملف الثابت `backend/reasoning_limits.json` كان غائبًا عن PyInstaller، فأعاد أول طلب محادثة500. أُضيف صراحة إلى سكربتي التغليف؛ أُعيد بناء sidecar واختُبرت المحادثة بعد الإصلاح. حُفظ الفشل السابق في `reports/completion-native-http-before-limits-fix.json` وسجل الخدمة.
- مهلة فحص المنفذ500 ms أعادت TimedOut على هذا Windows؛ أثبت probe Rust أن رفض الاتصال الصريح يصل بعد نحو2022 ms. أصبحت المهلة3000 ms مع رفض جميع النتائج غير ConnectionRefused كما كانت؛ لم يُسمح بالبدء عند timeout. الدليل `reports/completion-native-port-probe.log`، وأضيف نوع الخطأ ورقمه إلى سجل الفشل.
- بنية البناء الحالية: Python3.12.10 وPyInstaller6.22.3؛ Rust/Cargo1.99.1 وTauri CLI2.12.4 وcrate2.12.5؛ Vite7.3.8. استُخدمت الاعتماديات المحلية بلا تنزيلات وCargo offline/locked. إصلاح مهلة Rust أعاد الغلاف فقط مع sidecar المصحح نفسه؛ لا إعادة استخدام لخدمة ما قبل إصلاح JSON.

## البناء من الاعتماديات المثبتة

يتطلب البناء Python مع متطلبات المشروع وPyInstaller، وNode واعتماديات الواجهة/Tauri، وRust MSVC وأدوات C++ وWindows SDK. التشغيل يحتاج WebView2. راجع [متطلبات Tauri الرسمية](https://v2.tauri.app/start/prerequisites/).

```powershell
npm --prefix frontend run build
$env:CARGO_HOME = 'D:/RiwaqBuild/cargo'
$env:RUSTUP_HOME = 'D:/RiwaqBuild/rustup'
$env:Path = "$env:CARGO_HOME/bin;$env:Path"
./scripts/desktop-build.ps1 -BuildRoot D:/RiwaqBuild/next-candidate -CargoTargetDirectory D:/RiwaqBuild/target -NoBundle
```

لا تنفذ `npm ci` أو تنزيل Rust أو صور أو نماذج لمجرد إعادة البناء في البيئة الحالية. يثبت السكربت Cargo على وضع offline وlocked؛ يحتاج cache صالحًا سابقًا. الأمر الافتراضي يعيد بناء الخدمة كاملة، ويجمع الواجهة وملفات config وPython المطلوبة في sidecar، ثم يبني Tauri. لا تستخدم `-SkipPython` بعد أي تغيير backend أو frontend؛ هذا الخيار يعيد استخدام خدمة قديمة عمدًا.

المخرجات:

- `D:/RiwaqBuild/portable/Riwaq/riwaq.exe`: الغلاف الأصلي.
- `D:/RiwaqBuild/portable/Riwaq/riwaq-service.exe`: الخدمة المضمّنة.
- `D:/RiwaqBuild/portable/Riwaq/scripts/pair-browser.ps1`: إجراء الاقتران المحلي الصريح.
- `D:/RiwaqBuild/portable/Riwaq/manifest.json`: أحجام وبصمات الملفات؛ manifest البناء ليس إيصال اختبار تشغيل.
- `D:/RiwaqBuild/Riwaq-0.1.0-windows-x64-portable.zip`: مجلد محمول، وليس installer.

صيغة اسم sidecar داخل مصدر Tauri تتبع [externalBin الرسمي](https://v2.tauri.app/develop/sidecar/). مسار NSIS اختياري خارج هذا التحقق وقد يحتاج اعتماديات إضافية؛ لا يُشغّل ضمن إعادة البناء offline الحالية.

## التشغيل والاقتران والتخزين

شغّل `riwaq.exe` بعد فك المجلد كاملًا. يرفض الغلاف البدء بالخدمة إذا كان المنفذ8765 مشغولًا أو تعذّر إثبات أنه حر؛ **لا يثق بخادم موجود ولا يتصل به تلقائيًا**. لا يغلق الخدمة السابقة بدل المستخدم. عند السماح يبدأ فقط sidecar المجاور مخفيًا، وينتظر حالته ثم يفتح النافذة.

التخزين الافتراضي `%LOCALAPPDATA%/Riwaq`، أو قيمة `RIWAQ_DATA_DIR` الموروثة من عملية الإطلاق. لا تغيّر مسار البيانات عشوائيًا؛ يجب أن يستخدم إجراء الاقتران المجلد نفسه. بيانات اختبار الحزمة تُنشأ في مجلد مستقل ولا تستعمل قاعدة المستخدم الرئيسية.

بعد تشغيل النافذة، نفّذ محليًا من مجلد الحزمة:

```powershell
./scripts/pair-browser.ps1 -Copy
```

ثم ألصق الرمز في بوابة الاقتران. نسخ الرمز إجراء صريح، ولا يحدث تلقائيًا عند البدء. الإجراء يتحقق من هوية الخدمة بتحدي محلي مرتبط بمفتاح DPAPI قبل إصدار الرمز؛ الرمز قصير العمر وأحادي الاستخدام، والجلسة HttpOnly. هذه هوية مالك محلي واحد، وليست حسابات سحابية متعددة أو حماية من برنامج خبيث يملك حساب Windows نفسه. لا توضع الرموز في URL أو manifest أو سجل النموذج.

إغلاق الغلاف ينهي فقط شجرة sidecar التي بدأها، بما فيها عملية PyInstaller التابعة. قد يقطع ذلك توليدًا جاريًا؛ البيانات المحفوظة تستعاد، والرد غير المكتمل يُعلّم interrupted عند بدء الخدمة. زر إيقاف الرد يوفر إلغاءً منظمًا قبل الإغلاق.

## قدرات الغلاف وحدود الحزمة

- `Ctrl+Shift+Space` يركز النافذة الرئيسية باستخدام [Global Shortcut](https://v2.tauri.app/plugin/global-shortcut/)؛ ليست نافذة مصغرة مستقلة. قد يكون الاختصار محجوزًا لتطبيق آخر.
- صفحة الويب لا تتلقى صلاحيات Tauri للملفات أو shell. اختيار الملف تفاعل صريح، وتُحظر النوافذ الجديدة والتنقل خارج خدمة الجهاز. فتح المصادر الخارجية داخل الغلاف غير متاح حاليًا.
- فشل بدء الخدمة يعرض صفحة محلية، ويكتب سببًا مختصرًا في مجلد سجلات التطبيق `startup-error.txt`.
- لا تنزيل للنماذج أو صور Docker عند الإطلاق، ولا تحويل مهمة محلية إلى سحابة. المحادثة الفعلية تحتاج Ollama ونموذجًا محليًا متوافقًا موجودين خارج ZIP.
- عمال الصوت وتوليد/تصدير الصور وتركيب الفيديو والمستندات المتقدمة ليست معبأة كبيئة تشغيل مكتملة. الحراس يعيدون `packaged_worker_unavailable` أو عدم توفر الاعتماديات بدل تشغيل exe بالخيار الخاطئ أو الادعاء بميزة مختبرة. اختبارات المصدر لهذه العمال لا تعتمد الحزمة.
- محول Docker يتطلب إعدادًا خادميًا محليًا مثبتًا في مجلد البيانات، والمحرك والصور خارجيان. نجاحه من المصدر لا يثبت أن نسخة الحزمة الجديدة شغّلته. لا تنقل ملف إعداد QA إلى بيانات المستخدم تلقائيًا.
- النسخة الاحتياطية المحلية الكاملة لا تساوي snapshot JSON الخفيف. اتبع دليل المصدر `docs/RIWAQ_GUARD.md` واستعادة المجلد المعزول؛ لا تتجاوز quarantine أو تستعد قاعدة قديمة فوق البيانات الحالية.

## بديل نافذة Edge

`scripts/package-service.ps1` و`scripts/launch-web-desktop.ps1` يقدمان مسارًا منفصلًا لخدمة محلية ونافذة Edge. هذه نافذة متصفح وليست Tauri، ولا يثبت تشغيلها اختبارًا للغلاف الأصلي. يستخدم launcher ملف Edge مستقلًا ويمنع الوثوق بمنفذ سابق، ولا يستخدم ExecutionPolicy Bypass. التخزين الافتراضي لهذا البديل `%LOCALAPPDATA%/Riwaq/data` يختلف عن غلاف Tauri؛ إجراء الاقتران يجب أن يتبع المسار الصحيح.

## التحقق المطلوب للحزمة نفسها

افحص manifest وبصمات الغلاف والخدمة والواجهة أولًا. ثم شغّل exe ببيانات تجريبية ومنفذ حر، وتحقق من نافذة WebView2 الفعلية والاقتران والرد المحلي والحفظ والإلغاء والإغلاق وإعادة الفتح وإنهاء الطفل. افصل مشاهدة النافذة الأصلية عن اختبارات HTTP للخدمة، ولا تسجل ما تعذر كنجاح. فحص ZIP أو نجاح البناء أو محاكاة الردود لا يكمل هذا القبول.

التغطية غير المكتملة: الاقتران والمحادثة داخل WebView2 نفسه، الاختصار، المثبت والتوقيع. اختبارات HTTP لا تُسجل بدل هذه الحالات. الإغلاق وإعادة الفتح واستعادة الرسالة وحالة الإلغاء وانتهاء الشجرة المسجلة تحققت في جولة الاستئناف الثالثة؛ لا تعني اكتمال بقية القدرات أو عزل جميع عمال الوسائط.
